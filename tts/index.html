🎯 TTS 是什么

文本转语音（Text-to-Speech, TTS），目标是把文字转换成自然流畅的语音。它是导航播报、有声书、智能音箱、屏幕阅读器、数字人背后的核心技术。

🗣️通俗理解：TTS = 机器的"嗓子+朗读者"。给它一段文字，它要像人一样决定每个字读什么音、声调多高、时长多长、哪里停顿，最后"振动空气"生成声波。

TTS 的难度来自三个层面：

  • 自然度：不能像机器人一字一顿，要有韵律、语气、情感
  • 表现力：同一句话不同人/不同情绪说出来差异巨大，可控性是难题
  • 实时性：语音是 16kHz~24kHz 高维信号（每秒 1.6-2.4 万个采样点），生成要快

TTS 70 年同样经历了三次范式跃迁：共振峰合成（规则驱动）→ 拼接/参数合成（统计驱动）→ 神经合成（WaveNet/Tacotron/FastSpeech/VITS/VALL-E）。

🔤 文本前端 · TTS 的"字典+语法书"

TTS 不是直接把字喂给模型——在进入声学模型之前，必须经过文本前端（Text Frontend）处理，把文字变成语言学特征。

1️⃣ 文本归一化 TN

"192.168.1.1"→"一百九十二点一六八点一点一"；"2024年"→"二零二四年"或"两千二十四年"；"$5"→"五美元"。处理数字、日期、货币、缩写、符号。

2️⃣ 分词 / G2P

中文分词 + 多音字消歧（"行"=xíng/háng）；英文 Grapheme-to-Phoneme 转成音素（CMUdict 词典 + 模型预测未登录词）。

3️⃣ 韵律预测 Prosody

预测韵律层级：韵律词（PW）→ 韵律短语（PPH）→ 语调短语（IPH）→ 句（S）。决定哪里停顿、停多久，是自然度的关键。

⚠️前端处理不好，后面模型再强也读不对。中文 TTS 最常见的"读错字"问题，80% 出在前端（多音字/数字/缩写），而不是声学模型。端到端 TTS 试图跳过前端，但数字/符号/英文混读仍是痛点。

🎺 源-滤波模型 · 语音产生的物理直觉

1960 年 Fant 提出 源-滤波理论（Source-Filter Model），把语音产生拆成两个独立部分——这是所有 TTS 的物理基础。

🔊 声源 Source（声带振动）

浊音（元音）：声带周期性振动，产生脉冲序列，周期 = 1/F0（基频）
清音（辅音/s/sh/）：声带不振动，气流摩擦产生湍流噪声
爆破音：成阻-持阻-除阻，瞬间释放气流

🎺 滤波器 Filter（声道/口腔）

口腔+舌头+嘴唇的形状构成谐振腔，对声源频谱进行"调制"，形成若干个能量峰值——共振峰 Formant (F1, F2, F3…)。不同元音对应不同的 F1/F2 组合。

🎛️ 互动：元音 /a/ /i/ /u/ 的共振峰区别

点击不同元音，观察其共振峰位置：F1 与舌位高低负相关（舌越高 F1 越低），F2 与舌位前后正相关（舌越前 F2 越高）。

✂️ 单元拼接合成 · 2000 年代的主流

单元拼接合成（Concatenative TTS）的思路非常朴素：预先录制大量语音，切成小单元（音素/双音素 diphone/音节），合成时选最合适的单元拼接起来。

✅ 优点

  • 音质高（都是真人录音）
  • 在录音覆盖范围内自然度不错

❌ 缺点

  • 需要巨大音库（几小时到几十小时）
  • 拼接边界有"咔哒"声
  • 韵律不自然，像机器人
  • 无法换声音/情感/风格
  • 遇到未登录词必崩
💡你听过的早期导航（"前方-五百米-右转"）、老 Siri 早期版本、银行客服机器人，都是拼接合成。那种一个字一个字蹦出来的感觉，就是它。

📐 参数合成 · HMM/STRAIGHT 时代

统计参数合成（Statistical Parametric Speech Synthesis, SPSS）的代表是 HTS（HMM-based Speech Synthesis System）：不直接拼接波形，而是先预测声学参数（基频 F0、频谱包络、非周期分量），再用声码器（vocoder，如 STRAIGHT、WORLD）合成波形。

文本 → 前端 → HMM 序列 → 决策树聚类 → 参数生成 (MLPG) → 声码器 → 波形

参数化

不存储波形，存均值方差，模型小

灵活

可通过改 HMM 参数变换说话人/情感（说话人自适应、MLLR/CMLLR）

buzzy 问题

声码器过于平滑，合成语音有"闷/电子"感，MOS 普遍 3 分左右

🌊 WaveNet · 神经网络生成语音的开山之作

2016 年 DeepMind 的 WaveNet 是神经 TTS 的里程碑。它用自回归 + 扩张因果卷积逐样本生成波形，第一次让神经网络合成的语音 MOS 达到 4 分+。

核心创新

  • 因果卷积 Causal Conv：预测 t 时刻样本只能看 t 之前，保证自回归
  • 扩张卷积 Dilated Conv：卷积核带空洞（如 1,2,4,8,16,…,512），以少量层数获得指数级感受野，建模长程依赖
  • 门控激活 Gated Activation：z = tanh(Wf*x) ⊙ σ(Wg*x)，类似 LSTM 的门控
  • μ-law 量化 + Softmax：把 16bit 样本量化到 256 个值，做 256 分类
  • 残差+跳连接：堆叠 30 层仍能训练
# WaveNet 核心块的简化 PyTorch 实现
class WaveNetBlock(nn.Module):
  def __init__(self, channels, dilation):
    super().__init__()
    self.filter_conv = nn.Conv1d(channels, channels, 2, dilation=dilation, padding=0)
    self.gate_conv   = nn.Conv1d(channels, channels, 2, dilation=dilation, padding=0)
    self.res_proj    = nn.Conv1d(channels, channels, 1)
    self.skip_proj   = nn.Conv1d(channels, channels, 1)

  def forward(self, x):
    # 因果 + 门控 + tanh · sigmoid
    f = torch.tanh(self.filter_conv(x))
    g = torch.sigmoid(self.gate_conv(x))
    z = f * g
    skip = self.skip_proj(z)
    res  = self.res_proj(z) + x[:, :, -z.size(2):]  # 残差（裁剪对齐）
    return res, skip
⚠️WaveNet 的致命问题：太慢。逐样本自回归生成 1 秒音频需要几分钟——不能用于产品。所以它后来退化成"声码器"（把梅尔谱转波形），被 Parallel WaveNet / WaveRNN / HiFi-GAN 等更快的方法取代。

🎼 Tacotron 2 · 现代神经 TTS 的标准范式

2018 年 Google 的 Tacotron 2 确立了现代 TTS 的"两段式"标准流水线：声学模型（文本 → 梅尔谱） + 神经声码器（梅尔谱 → 波形）。

字符/音素 → 编码器 Encoder → 注意力 Attention → 解码器 Decoder → 梅尔谱 → WaveNet/Griffin-Lim → 波形

架构拆解

📥 编码器

3 层 1D Conv + BiLSTM，把字符序列编码成隐表征

🎯 Location-Sensitive Attention

在注意力打分中加入"累积注意力权重"，防止重复/漏字——是 Tacotron2 训练稳定的关键

📤 自回归解码器

2 层 LSTM PreNet + 2 层 LSTM AttentionRNN + 投影到 80 维梅尔谱；最后一个"stop token"预测什么时候结束

# Tacotron 2 解码核心伪代码
def decode(encoder_out, inputs):
    dec_input = <GO_FRAME>
    dec_hidden, ctx, attn_weights = init()
    mel_frames = []; stop_flags = []

        if stop_prob > 0.5: break

    return PostNet(mel_frames)   # 5层CNN残差修正
💡Tacotron 2 MOS 4.5，几乎与录音难以分辨。但它自回归逐帧生成梅尔谱，还是慢；而且注意力对长文本不稳定，会漏字重复。这催生了 FastSpeech 系列非自回归模型。

⚡ FastSpeech 2 · 非自回归工业之王

2019/2020 年微软的 FastSpeech / FastSpeech 2 提出非自回归（Non-Autoregressive, NAR）架构：一次并行生成所有梅尔帧，推理速度比 Tacotron 2 快 270 倍（GPU 上 RTF ≈ 0.003，即生成 1 秒音频只需 3 毫秒）。

关键创新：时长预测器 + 长度规整器

非自回归最大的难点是音素到声学帧的对齐（每个音素对应几帧）。FastSpeech 的解决方案：

  1. 先用一个教师模型（Tacotron 2）训练好，用它的注意力权重或 Montreal Forced Alignment（MFA）提取每个音素的时长
  2. 训练一个 Duration Predictor（2 层 Conv + 1 层 Linear）从音素隐状态预测时长
  3. Length Regulator：根据预测的时长把每个音素的隐状态复制 N 份，扩展到帧级别
音素序列 Hp = [h1, h2, ..., hn] → LengthRegulator(Hp, d) = [h1×d1, h2×d2, ..., hn×dn] → Feed-Forward Transformer → 梅尔谱

FastSpeech 2 进一步加入了 音高 F0 预测器和 能量预测器，把 Tacotron 隐式学到的韵律信息显式建模，自然度追平 Tacotron 2（MOS 4.6），同时保持极高速度。

🏭FastSpeech 2 至今是工业部署首选：微软 Azure TTS、阿里 CosyVoice 编码器部分、字节豆包 TTS 都基于类似架构。

🎛️ 声码器家族 · 从波形到波形

声码器（Vocoder）负责把梅尔谱转成波形——这一步的音质直接决定 TTS 最终效果。声码器经历了几代演进：

🔥 HiFi-GAN · 当前声码器的事实标准

HiFi-GAN（2020，Kong et al.）用一个巧妙的多感受野设计，同时保证高频细节和长程连贯性，成为开源社区最广泛使用的声码器。

核心设计

  • 多感受野模块 MRF：每个残差块内并联 3 组不同 kernel/dilation 的卷积，同时看不同尺度的上下文
  • 多周期判别器 MPD：对输入按 [2,3,5,7,11] 等间隔采样，分别判别，捕捉不同周期的谐波
  • 多尺度判别器 MSD：在原始 / 2×下采样 / 4×下采样上分别判别，捕捉整体+细节
  • Generator 是纯 CNN（上采样 + MRF），一次前向出波形，无自回归
# HiFi-GAN Generator 核心上采样块（简化）
class ResBlock(nn.Module):
  def __init__(self, ch, kernel, dilations):
    self.convs = nn.ModuleList([
      nn.LeakyReLU(0.1),
      nn.utils.weight_norm(nn.Conv1d(ch, ch, kernel, dilation=d, padding=...))
      for d in dilations
    ])
  def forward(self, x):
    for c in self.convs: x = x + c(x)  # 残差
    return x

🎭 VITS · 端到端 TTS 的开源标杆

2021 年 Kakao 的 VITS（Variational Inference with adversarial learning for end-to-end Text-to-Speech）把声学模型 + 声码器合并成一个端到端模型，一个 VITS 直接从音素生成波形，无需两阶段训练。

三大支柱

1️⃣ VAE（变分推断）

用变分自编码器把语音隐变量建模为分布，训练时用真实语音做 posterior encoder 得到 z，推理时从 prior predictor 采样。这让 VITS 有"一对多"的多样性（同一句话每次说的不一样）。

2️⃣ Normalizing Flow

用若干层可逆仿射耦合层（Residual Coupling）把先验分布变得更复杂，建模语音的复杂分布。

3️⃣ GAN 对抗训练

把 HiFi-GAN 的判别器搬过来直接对波形做对抗训练，省去了单独的声码器训练。

音素 → Text Encoder → Prior Predictor (Flow) → z → Decoder (HiFi-GAN 风格) → 波形 训练时：Posterior Encoder 从真实梅尔谱提取 z，与先验对齐；MAS (Monotonic Alignment Search) 自动找对齐
⭐VITS 是目前中文开源 TTS 的绝对主力：Bert-VITS2、GPT-SoVITS、FishSpeech 等知名项目都基于 VITS 架构扩展（加入 BERT 韵律、LLM 先验、SDP 随机时长等）。

🤖 VALL-E · 零样本语音克隆的新纪元

2023 年微软的 VALL-E 把 TTS 从"声学模型"变成了"语言模型"——用 6 万小时语音训练一个 codec 语言模型，只需 3 秒未见过的说话人录音，就能克隆其声音、语调、情感。

核心思想：语音 = 离散 codec token

  1. 用预训练好的神经音频 codec（EnCodec，3 层量化，共 1024 个 token/layer）把波形压缩成离散 token 序列
  2. 第一阶段：AR 语言模型根据音素和 3 秒提示，自回归预测第一层 codec token（捕捉语义和说话人身份）
  3. 第二阶段：NAR 模型根据第一层预测其他 7 层 codec token（捕捉声学细节）
  4. 把 8 层 token 喂回 EnCodec 解码器，得到波形
🧠VALL-E 的革命性在于：它把 TTS 当成了"语音版 GPT"——in-context learning 能力让它不微调就能克隆新声音。随后出现的 Voicebox（Meta，Flow Matching）、NaturalSpeech 2/3（微软）、Speak Foreign、FishSpeech-1.5、Seed-TTS 等都是这个方向的延伸。

✅ 优点

  • 零样本 3 秒克隆
  • 声音/情感/韵律多样性高
  • 跨语种、代码混读能力强
  • 可自然重复、犹豫、笑声（在 prompt 中有）

⚠️ 问题

  • 稳定性差：可能漏字、重复、怪音
  • 长文本连贯性不足
  • 算力要求高
  • 伦理风险：声音伪造滥用

💻 源码走读 · Tacotron2 注意力机制

Tacotron 2 的 Location-Sensitive Attention 是它能稳定对齐的关键——区别于普通 Bahdanau 注意力，它加入了"累积注意力权重"作为额外特征，防止注意力反复看同一个位置：

# Location-Sensitive Attention 打分（Tacotron 2）
class LocationSensitiveAttention(nn.Module):
  def __init__(self, attn_rnn_ch, enc_ch, attn_ch, attn_conv_n=32, attn_conv_w=15):
    self.query_proj = nn.Linear(attn_rnn_ch, attn_ch, bias=False)
    self.loc_proj   = nn.Linear(attn_conv_n, attn_ch, bias=False)
    self.v          = nn.Linear(attn_ch, 1, bias=False)
    self.loc_conv   = nn.Conv1d(2, attn_conv_n, attn_conv_w, padding=attn_conv_w//2, bias=False)
    # memory 是 encoder 输出，提前投影一次
    self.memory_proj = nn.Linear(enc_ch, attn_ch, bias=False)

  def forward(self, query, memory, prev_attn, prev_attn_cum):
    # query: [B, attn_rnn_ch]; memory: [B, T, enc_ch]
    cat_prev = torch.cat([prev_attn.unsqueeze(1), prev_attn_cum.unsqueeze(1)], dim=1) # [B,2,T]
    loc_feat = self.loc_conv(cat_prev).transpose(1,2)                             # [B,T,C]
    scores = self.v(torch.tanh(
        self.query_proj(query).unsqueeze(1)    # [B,1,C]
      + self.memory_proj(memory)               # [B,T,C]
      + self.loc_proj(loc_feat)                # [B,T,C] ← 关键位置特征
    )).squeeze(-1)                              # [B,T]
    weights = F.softmax(scores, dim=-1)
    context = torch.bmm(weights.unsqueeze(1), memory).squeeze(1)
    return context, weights
