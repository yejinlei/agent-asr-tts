🎯 TTS 是什么

文本转语音（Text-to-Speech, TTS），目标是把文字转换成自然流畅的语音。它是导航播报、有声书、智能音箱、屏幕阅读器、数字人背后的核心技术。

🗣️通俗理解：TTS = 机器的"嗓子+朗读者"。给它一段文字，它要像人一样决定每个字读什么音、声调多高、时长多长、哪里停顿，最后"振动空气"生成声波。

TTS 的难度来自三个层面：

  • 自然度：不能像机器人一字一顿，要有韵律、语气、情感
  • 表现力：同一句话不同人/不同情绪说出来差异巨大，可控性是难题
  • 实时性：语音是 16kHz~24kHz 高维信号（每秒 1.6-2.4 万个采样点），生成要快

TTS 70 年同样经历了三次范式跃迁：共振峰合成（规则驱动）→ 拼接/参数合成（统计驱动）→ 神经合成（WaveNet/Tacotron/FastSpeech/VITS/VALL-E）。

🔤 文本前端 · TTS 的"字典+语法书"

TTS 不是直接把字喂给模型——在进入声学模型之前，必须经过文本前端（Text Frontend）处理，把文字变成语言学特征。

1️⃣ 文本归一化 TN

"192.168.1.1"→"一百九十二点一六八点一点一"；"2024年"→"二零二四年"或"两千二十四年"；"$5"→"五美元"。处理数字、日期、货币、缩写、符号。

2️⃣ 分词 / G2P

中文分词 + 多音字消歧（"行"=xíng/háng）；英文 Grapheme-to-Phoneme 转成音素（CMUdict 词典 + 模型预测未登录词）。

3️⃣ 韵律预测 Prosody

预测韵律层级：韵律词（PW）→ 韵律短语（PPH）→ 语调短语（IPH）→ 句（S）。决定哪里停顿、停多久，是自然度的关键。

⚠️前端处理不好，后面模型再强也读不对。中文 TTS 最常见的"读错字"问题，80% 出在前端（多音字/数字/缩写），而不是声学模型。端到端 TTS 试图跳过前端，但数字/符号/英文混读仍是痛点。

🎺 源-滤波模型 · 语音产生的物理直觉

1960 年 Fant 提出 源-滤波理论（Source-Filter Model），把语音产生拆成两个独立部分——这是所有 TTS 的物理基础。

🔊 声源 Source（声带振动）

浊音（元音）：声带周期性振动，产生脉冲序列，周期 = 1/F0（基频）
清音（辅音/s/sh/）：声带不振动，气流摩擦产生湍流噪声
爆破音：成阻-持阻-除阻，瞬间释放气流

🎺 滤波器 Filter（声道/口腔）

口腔+舌头+嘴唇的形状构成谐振腔，对声源频谱进行"调制"，形成若干个能量峰值——共振峰 Formant (F1, F2, F3…)。不同元音对应不同的 F1/F2 组合。

🎛️ 互动：元音 /a/ /i/ /u/ 的共振峰区别

点击不同元音，观察其共振峰位置：F1 与舌位高低负相关（舌越高 F1 越低），F2 与舌位前后正相关（舌越前 F2 越高）。

🎚️ YIN 基频提取 · 找到声带振动频率

基频 F0（Fundamental Frequency） 是声带每秒振动次数，决定音高。男声约 80–200Hz，女声约 160–400Hz。YIN 算法（2002, de Cheveigné）是 WORLD、Pyin 等主流声码器的核心。

🎼 YIN：从差分函数找周期

1原理图

2通俗原理

想象你在听一段"啊——"的元音：声带每秒开合 200 次，波形看起来像一串等间隔的"尖峰"。基频 F0 就是这串尖峰的间隔的倒数：间隔 5ms → F0 = 1/0.005 = 200Hz。

最直接的想法是"自相关函数"——把信号平移 τ，看它和自己有多像；最像的 τ 就是周期。但声音会慢慢变大变小（振幅调制），ACF 会被"骗"。YIN 的核心改进：用差分函数 d_t(τ) = Σ(x[t+j]−x[t+j+τ])²，它在 τ 恰好是一个周期时等于 0（因为周期信号 x[t+j] = x[t+j+T₀]），不受振幅整体缩放影响；再除以 1..τ 的平均差分做累积均值归一化，把谷压到 1 以下，用绝对阈值（0.1~0.15）找第一个过阈值的 τ*，最后做抛物线插值得到亚采样精度，F0 = Fs/τ*。

3数学公式

$$d_t(\tau) = \sum_{j=1}^{W}\big(x[t+j] - x[t+j+\tau]\big)^2$$ $$d'_t(\tau) = \begin{cases} 1, & \tau=0 \\ \dfrac{d_t(\tau)}{\frac{1}{\tau}\sum_{k=1}^{\tau}d_t(k)}, & \tau>0 \end{cases}$$ $$\tau^* = \min\{\tau \mid d'_t(\tau) < \theta\}, \quad F_0 = \dfrac{F_s}{\tau^* + \delta}$$
符号说明：
x[t]语音波形采样点
W差分计算窗口长度（通常取帧长的一半）
τ延迟（候选周期，单位采样点）
d_t(τ)差分函数（YIN 核心）
d'_t(τ)累积均值归一化差分函数（CMNDF）
θ绝对阈值（默认 0.1~0.15）
δ抛物线插值修正量（亚采样精度）
F_s采样率（如 16000Hz）

4从零手搓（NumPy，不调 librosa/pyin）

# ============ YIN 基频提取（纯 NumPy 实现） ============
import numpy as np

def yin_pitch(x, fs=16000, frame_len=1024, hop=256,
              f0_min=60, f0_max=500, threshold=0.1):
    # 搜索范围：周期 τ 对应 [fs/f0_max, fs/f0_min] 采样点
    tau_min = int(fs / f0_max)
    tau_max = int(fs / f0_min)
    f0s = []
    for start in range(0, len(x) - frame_len, hop):
        frame = x[start : start + frame_len].astype(np.float64)
        frame -= frame.mean()
        W = frame_len // 2

        # ① 差分函数 d(τ) = Σ (x[j]-x[j+τ])²  等价展开加速
        ac = np.correlate(frame[:W+tau_max], frame[:W+tau_max], 'full')
        ac = ac[W+tau_max-1 : W+tau_max-1 + tau_max+1]   # 自相关 r(τ)
        d = ac[0] + ac[0] - 2*ac                          # d(τ) = r(0)+r(0)-2r(τ)

        # ② 累积均值归一化 CMNDF
        dnorm = np.ones_like(d)
        cumsum = 0.0
        for tau in range(tau_min, tau_max+1):
            cumsum += d[tau]
            dnorm[tau] = d[tau] * tau / (cumsum + 1e-10)

        # ③ 绝对阈值搜索：找 dnorm 第一个低于阈值的谷
        tau_est = -1
        for tau in range(tau_min, tau_max):
            if dnorm[tau] < threshold and dnorm[tau] < dnorm[tau+1] and dnorm[tau] < dnorm[tau-1]:
                tau_est = tau; break
        if tau_est == -1:
            f0s.append(0.0); continue                   # 清音/无声

        # ④ 抛物线插值获得亚采样精度
        a, b, c = dnorm[tau_est-1], dnorm[tau_est], dnorm[tau_est+1]
        delta = 0.5*(a - c)/(a - 2*b + c + 1e-10)
        f0s.append(fs / (tau_est + delta))
    return np.array(f0s)

# ============ 测试：合成一段 220Hz 正弦，反推 F0 ============
fs = 16000; t = np.arange(0, 1.0, 1/fs)
x = np.sin(2*np.pi*220*t)                              # 220Hz 纯音
f0 = yin_pitch(x, fs)
print("估出 F0 = %.1f Hz (真值 220)" % np.median(f0[f0>0]))
💡 复制到 Python 环境直接运行，控制台应打印 ≈220Hz。

📐 LPC 线性预测 · 声道滤波器与共振峰

LPC（Linear Predictive Coding） 是源-滤波理论的经典实现：用过去 p 个采样点线性预测当前点，预测系数就是声道包络；从系数求根即可得到 F1/F2/F3 共振峰。

🎼 LPC + Levinson-Durbin 递推求共振峰

1原理图

2通俗原理

声道是一根"管子"，声音在里面来回反射形成共振峰。从数学上看，这种谐振系统可以用全极点模型（只含分母极点的滤波器）很好地近似，而"过去 p 个点线性组合预测当前点"正好对应一个全极点 IIR 滤波器。

具体做法：对一帧加窗语音算它的自相关 r[k]，再用Levinson-Durbin 递推（O(p²) 复杂度）解 Toeplitz 线性方程组，得到 LPC 系数 a₁…a_p。把 a 组成多项式 A(z) = 1 − Σ a_k z⁻ᵏ，求根后保留单位圆附近的共轭对，每个根的角度对应一个共振峰频率 F = angle·Fs/(2π)，半径对应带宽。这就是老派声码器（STRAIGHT/WORLD 早期）提取频谱包络与共振峰的标准做法。

3数学公式

$$\hat{x}[n] = \sum_{k=1}^{p} a_k\, x[n-k], \qquad e[n] = x[n] - \hat{x}[n]$$ $$\min_{\mathbf{a}}\sum_n e[n]^2 \;\Longleftrightarrow\; \mathbf{R}\mathbf{a} = \mathbf{r}\quad(\text{Yule-Walker})$$ $$A(z) = 1 - \sum_{k=1}^{p} a_k z^{-k},\qquad z_k = r_k e^{j\theta_k},\quad F_k = \dfrac{\theta_k}{2\pi}\,F_s$$
符号说明：
pLPC 阶数（通常 2+采样率kHz，16k 取 12~16）
a_kLPC 系数（声道滤波器分母系数）
r[k]自相关函数 r[k]=Σ x[n]x[n−k]
E预测残差能量（Levinson 递推里的 E）
A(z)逆滤波器（分析滤波器），H(z)=G/A(z) 是合成滤波器
z_k, θ_kA(z)=0 的根及其辐角
F_k第 k 个共振峰频率

4从零手搓（NumPy 手搓 Levinson-Durbin）

# ============ LPC + 共振峰提取（纯 NumPy） ============
import numpy as np

def lpc(frame, order):
    # 自相关
    x = frame - frame.mean()
    r = np.correlate(x, x, 'full')[len(x)-1:]
    r = r[: order+1]
    # Levinson-Durbin 递推（手搓 E/k/a 迭代）
    a = np.zeros(order+1); a[0] = 1.0
    E = r[0]
    for i in range(1, order+1):
        k = (r[i] - np.dot(a[1:i], r[i-1:0:-1])) / E   # 反射系数
        a[i] = k
        a[1:i] -= k * a[i-1:0:-1]
        E *= (1 - k*k)
    return a, E

def formants_from_lpc(a, fs, n_formants=3):
    # 求 A(z) 多项式的根
    roots = np.roots(a)
    # 取上半平面（正频率）、单位圆内
    roots = roots[np.imag(roots) > 1e-3]
    # 辐角 → 频率；带宽 = -ln|r|·Fs/π
    freqs = np.angle(roots) * fs / (2*np.pi)
    bws   = -np.log(np.abs(roots)) * fs / np.pi
    # 按频率排序，只留合理带宽的（<500Hz）
    order_idx = np.argsort(freqs)
    F = []
    for i in order_idx:
        if bws[i] < 500 and 90 < freqs[i] < fs/2-100:
            F.append(freqs[i])
        if len(F) >= n_formants: break
    return F

# ============ 测试：合成 /a/ 元音（F1=730, F2=1090, F3=2440） ============
fs = 16000; dur = 0.05; t = np.arange(0, dur, 1/fs)
x = np.zeros_like(t)
for F, bw in [(730,80),(1090,90),(2440,150)]:
    x += np.exp(-bw*t) * np.sin(2*np.pi*F*t)
x *= 0.5*(1+np.sin(2*np.pi*t/dur))                 # 简单窗
win = np.hanning(len(x)); x *= win
a, E = lpc(x, order=12)
F = formants_from_lpc(a, fs)
print("估出共振峰 F1/F2/F3 = ", [round(f,0) for f in F])
💡 复制运行应输出接近 730/1090/2440Hz 的 F1/F2/F3。

🔄 Griffin-Lim 声码器 · 相位迭代重建

最简单的"声码器"不需要训练——给定幅度谱（或 Mel 谱反变换得到的线性谱幅度），通过反复在时域/频域投影就能重建波形，这就是 Griffin-Lim（1984）算法。它是无数 TTS 项目入门的"基线声码器"。

🎼 Griffin-Lim：反复 STFT ↔ ISTFT 找回相位

1原理图

2通俗原理

STFT 把一段波形切成很多帧，每帧做 FFT 得到"幅度 + 相位"两个信息。人耳对相位不敏感，但对幅度极度敏感——所以 TTS 模型通常只预测 Mel 幅度谱。问题来了：只有幅度怎么反推回波形？缺少相位！

Griffin-Lim 的思路非常"工程师"：随便给一个初始相位，反复在时域和频域之间来回跑——每次到频域就把幅度替换成已知的真实幅度（只保留刚算出来的相位），每次到时域就用 ISTFT 合成。反复迭代之后，相位会逐渐"自洽"（相邻帧相位连续、STFT 一致性约束被满足），得到一个听起来还不错的波形。它不需要训练、没有参数，是最朴素但最通用的基线。缺点是音质发闷、有"金属感"，迭代次数多了也慢。

3数学公式

$$\mathbf{X}^{(0)} = |\mathbf{S}|\odot e^{j\phi_0},\qquad \phi_0\sim\mathcal{U}(-\pi,\pi)$$ $$\mathbf{x}^{(n)} = \mathrm{iSTFT}\!\big(\mathbf{X}^{(n)}\big)$$ $$\phi^{(n+1)} = \angle\,\mathrm{STFT}\!\big(\mathbf{x}^{(n)}\big),\quad \mathbf{X}^{(n+1)} = |\mathbf{S}|\odot e^{j\phi^{(n+1)}}$$ $$\mathbf{x}^{*} = \mathrm{iSTFT}\!\big(\mathbf{X}^{(N)}\big)$$
符号说明：
|S|已知目标幅度谱（如线性谱，形状 F×T）
φ₀初始随机相位
X⁽ⁿ⁾第 n 次迭代的复频谱
⊙逐元素相乘
N迭代次数（通常 32~100）
∠(·)取相位角（复数 → angle）

4从零手搓（NumPy 手写 STFT/ISTFT，不调 librosa）

# ============ Griffin-Lim（纯 NumPy） ============
import numpy as np

def stft(x, n_fft=1024, hop=256, win=None):
    if win is None: win = np.hanning(n_fft)
    T = 1 + (len(x) - n_fft) // hop
    X = np.zeros((n_fft//2+1, T), dtype=np.complex128)
    for t in range(T):
        seg = x[t*hop : t*hop+n_fft] * win
        X[:, t] = np.fft.rfft(seg)
    return X

def istft(X, n_fft=1024, hop=256, win=None):
    if win is None: win = np.hanning(n_fft)
    T = X.shape[1]; L = (T-1)*hop + n_fft
    x = np.zeros(L); wsum = np.zeros(L)
    for t in range(T):
        seg = np.fft.irfft(X[:, t], n=n_fft) * win
        x[t*hop : t*hop+n_fft] += seg
        wsum[t*hop : t*hop+n_fft] += win*win
    return x / (wsum + 1e-8)                   # 归一化去窗影响

def griffin_lim(mag, n_fft=1024, hop=256, n_iter=60):
    # mag: (F, T) 幅度谱。随机相位初始化
    phase = np.exp(2j*np.pi * np.random.rand(*mag.shape))
    X = mag * phase
    for i in range(n_iter):
        x = istft(X, n_fft, hop)
        X_hat = stft(x, n_fft, hop)
        # 保留新相位，幅度强制替换为目标
        phase = X_hat / (np.abs(X_hat) + 1e-8)
        X = mag * phase
    return istft(X, n_fft, hop)

# ============ 测试：对一段正弦做 STFT→只保留幅度→GL 重建 ============
fs=16000; t=np.arange(0,1.0,1/fs)
x = 0.5*np.sin(2*np.pi*440*t)
X = stft(x); mag = np.abs(X)
x_r = griffin_lim(mag, n_iter=60)
snr = 10*np.log10(np.sum(x[:len(x_r)]**2) / np.sum((x[:len(x_r)]-x_r)**2))
print(f"重建 SNR = {snr:.1f} dB（越高越好）")
💡 复制运行，60 次迭代后 SNR 一般 >15dB，已能清晰听出原音。

✂️ 单元拼接合成 · 2000 年代的主流

单元拼接合成（Concatenative TTS）的思路非常朴素：预先录制大量语音，切成小单元（音素/双音素 diphone/音节），合成时选最合适的单元拼接起来。

✅ 优点

  • 音质高（都是真人录音）
  • 在录音覆盖范围内自然度不错

❌ 缺点

  • 需要巨大音库（几小时到几十小时）
  • 拼接边界有"咔哒"声
  • 韵律不自然，像机器人
  • 无法换声音/情感/风格
  • 遇到未登录词必崩
💡你听过的早期导航（"前方-五百米-右转"）、老 Siri 早期版本、银行客服机器人，都是拼接合成。那种一个字一个字蹦出来的感觉，就是它。

📐 参数合成 · HMM/STRAIGHT 时代

统计参数合成（Statistical Parametric Speech Synthesis, SPSS）的代表是 HTS（HMM-based Speech Synthesis System）：不直接拼接波形，而是先预测声学参数（基频 F0、频谱包络、非周期分量），再用声码器（vocoder，如 STRAIGHT、WORLD）合成波形。

文本 → 前端 → HMM 序列 → 决策树聚类 → 参数生成 (MLPG) → 声码器 → 波形

参数化

不存储波形，存均值方差，模型小

灵活

可通过改 HMM 参数变换说话人/情感（说话人自适应、MLLR/CMLLR）

buzzy 问题

声码器过于平滑，合成语音有"闷/电子"感，MOS 普遍 3 分左右

🌊 WaveNet · 神经网络生成语音的开山之作

2016 年 DeepMind 的 WaveNet 是神经 TTS 的里程碑。它用自回归 + 扩张因果卷积逐样本生成波形，第一次让神经网络合成的语音 MOS 达到 4 分+。

核心创新

  • 因果卷积 Causal Conv：预测 t 时刻样本只能看 t 之前，保证自回归
  • 扩张卷积 Dilated Conv：卷积核带空洞（如 1,2,4,8,16,…,512），以少量层数获得指数级感受野，建模长程依赖
  • 门控激活 Gated Activation：z = tanh(Wf*x) ⊙ σ(Wg*x)，类似 LSTM 的门控
  • μ-law 量化 + Softmax：把 16bit 样本量化到 256 个值，做 256 分类
  • 残差+跳连接：堆叠 30 层仍能训练
# WaveNet 核心块的简化 PyTorch 实现
import torch, torch.nn as nn

class WaveNetBlock(nn.Module):
  def __init__(self, channels, dilation):
    super().__init__()
    self.filter_conv = nn.Conv1d(channels, channels, 2, dilation=dilation, padding=0)
    self.gate_conv   = nn.Conv1d(channels, channels, 2, dilation=dilation, padding=0)
    self.res_proj    = nn.Conv1d(channels, channels, 1)
    self.skip_proj   = nn.Conv1d(channels, channels, 1)

  def forward(self, x):
    f = torch.tanh(self.filter_conv(x))
    g = torch.sigmoid(self.gate_conv(x))
    z = f * g
    skip = self.skip_proj(z)
    res  = self.res_proj(z) + x[:, :, -z.size(2):]
    return res, skip
⚠️WaveNet 的致命问题：太慢。逐样本自回归生成 1 秒音频需要几分钟——不能用于产品。所以它后来退化成"声码器"（把梅尔谱转波形），被 Parallel WaveNet / WaveRNN / HiFi-GAN 等更快的方法取代。

🎼 Tacotron 2 · 现代神经 TTS 的标准范式

2018 年 Google 的 Tacotron 2 确立了现代 TTS 的"两段式"标准流水线：声学模型（文本 → 梅尔谱） + 神经声码器（梅尔谱 → 波形）。编码器把字符/音素读成"记忆"，解码器自回归地一帧一帧生成 Mel 谱，每步通过位置敏感注意力（Location-Sensitive Attention）决定"当前在读哪个字"。

🎼 Mini-Tacotron 2：Seq2Seq + LSA 注意力

1原理图

2通俗原理

Tacotron 2 像一个"看着稿子逐句念"的朗读者：

  • 编码器 Encoder 先把整段文字读一遍，把每个字/音素变成一个向量（Memory），存在"脑子里"；
  • 解码器 Decoder 每次生成一帧 Mel（12.5ms 语音），生成前先用注意力"看一眼稿子当前念到哪里"，取对应位置的文字向量（上下文向量），结合上一帧自己生成的内容，吐出下一帧；
  • 位置敏感注意力 LSA 的关键是给注意力加"已经读过哪里"的累计信息，防止朗读者"反复读同一个字"或"跳字"——这是 Tacotron2 训练稳定的秘诀。
  • 最后一个特殊的 Stop Token 头预测"这段话念完了"，停止生成。再经过一个 5 层 CNN 的 PostNet 残差修正，得到最终 Mel 谱。

3数学公式

$$e_{t,i} = \mathbf{v}^\top\tanh\!\big(\mathbf{W}\mathbf{h}_i + \mathbf{V}\mathbf{s}_t + \mathbf{U}\mathbf{f}_{t,i} + \mathbf{b}\big)$$ $$\mathbf{f}_{t} = \mathbf{F}*\sum_{k<t}\boldsymbol{\alpha}_{k},\qquad \alpha_{t,i} = \mathrm{softmax}_i(e_{t,i})$$ $$\mathbf{c}_t = \sum_{i}\alpha_{t,i}\mathbf{h}_i,\qquad P(\text{stop}\mid t)=\sigma(\mathbf{w}_s^\top[\mathbf{s}_t;\mathbf{c}_t])$$
符号说明：
h_iEncoder 第 i 个音素的隐向量（Memory）
s_tDecoder 在 t 步的隐状态
f_{t,i}位置特征（卷积累积注意力权重）
α_{t,i}t 步对第 i 个音素的注意力权重
c_t上下文向量（对 h_i 的加权和）
W, V, U, v可学习参数

4从零手搓（PyTorch 简化可运行 Mini-Tacotron）

# ============ Mini-Tacotron2（PyTorch 简化版） ============
import torch, torch.nn as nn, torch.nn.functional as F

class MiniTacotron(nn.Module):
    def __init__(self, n_vocab=50, emb_dim=64, enc_dim=128,
                 dec_dim=256, mel_dim=80, attn_dim=128, attn_n=32, attn_k=15):
        super().__init__()
        self.emb = nn.Embedding(n_vocab, emb_dim)
        self.enc_conv = nn.Sequential(
            nn.Conv1d(emb_dim, enc_dim, 5, padding=2), nn.ReLU(),
            nn.Conv1d(enc_dim, enc_dim, 5, padding=2), nn.ReLU(),
            nn.Conv1d(enc_dim, enc_dim, 5, padding=2), nn.ReLU())
        self.enc_lstm = nn.LSTM(enc_dim, enc_dim//2, 1, batch_first=True, bidirectional=True)

        self.prenet = nn.Sequential(nn.Linear(mel_dim, dec_dim), nn.ReLU(), nn.Dropout(0.5),
                                    nn.Linear(dec_dim, dec_dim), nn.ReLU(), nn.Dropout(0.5))
        self.dec_lstm = nn.LSTMCell(dec_dim+enc_dim, dec_dim)
        self.loc_conv = nn.Conv1d(2, attn_n, attn_k, padding=attn_k//2, bias=False)
        self.q_proj = nn.Linear(dec_dim, attn_dim, bias=False)
        self.mem_proj = nn.Linear(enc_dim, attn_dim, bias=False)
        self.loc_proj = nn.Linear(attn_n, attn_dim, bias=False)
        self.v = nn.Linear(attn_dim, 1, bias=False)
        self.mel_proj = nn.Linear(dec_dim+enc_dim, mel_dim)
        self.stop_proj = nn.Linear(dec_dim+enc_dim, 1)

    def encode(self, tokens):
        x = self.emb(tokens).transpose(1,2)           # [B,T,E]
        x = self.enc_conv(x).transpose(1,2)
        h, _ = self.enc_lstm(x)
        return h                                       # memory [B,T,enc_dim]

    def attention(self, s_t, mem, prev_a, prev_a_cum):
        cat = torch.stack([prev_a, prev_a_cum], dim=1)# [B,2,T]
        f = self.loc_conv(cat).transpose(1,2)        # [B,T,attn_n]
        e = self.v(torch.tanh(self.q_proj(s_t).unsqueeze(1)
                            + self.mem_proj(mem)
                            + self.loc_proj(f))).squeeze(-1)
        a = F.softmax(e, dim=-1)
        ctx = torch.bmm(a.unsqueeze(1), mem).squeeze(1)
        return ctx, a

    def forward(self, tokens, max_frames=200):
        B = tokens.size(0)
        mem = self.encode(tokens)
        T = mem.size(1)
        s = torch.zeros(B, self.dec_lstm.hidden_size, device=tokens.device)
        c = torch.zeros_like(s)
        hx, cx = torch.zeros_like(s), torch.zeros_like(s)
        prev_a = torch.zeros(B, T, device=tokens.device); prev_a[:,0] = 1.0
        prev_a_cum = torch.zeros_like(prev_a)
        mel_in = torch.zeros(B, self.mel_proj.out_features, device=tokens.device)
        mels, stops, attns = [], [], []
        for t in range(max_frames):
            p = self.prenet(mel_in)
            hx, cx = self.dec_lstm(torch.cat([p, c], dim=-1), (hx, cx))
            ctx, a = self.attention(hx, mem, prev_a, prev_a_cum)
            out = torch.cat([hx, ctx], dim=-1)
            mel_frame = self.mel_proj(out)
            stop = torch.sigmoid(self.stop_proj(out)).squeeze(-1)
            mels.append(mel_frame); stops.append(stop); attns.append(a)
            prev_a_cum = prev_a_cum + a; prev_a = a; mel_in = mel_frame
            if (stop > 0.5).all(): break
        return torch.stack(mels,1), torch.stack(stops,1), torch.stack(attns,1)

# 快速前向推理（不训练，展示流水线）
m = MiniTacotron(); m.eval()
tokens = torch.randint(0, 50, (1, 20))
with torch.no_grad():
    mel, stop, attn = m(tokens)
print("mel shape:", mel.shape, "attn shape:", attn.shape)

⚡ FastSpeech 2 · 非自回归工业之王

Tacotron 2 自回归慢、且对长文本注意力容易对齐失败。2019/2020 年微软提出 FastSpeech / FastSpeech 2：非自回归（NAR）一次并行生成所有 Mel 帧，速度比 Tacotron 2 快 270 倍（GPU 上 RTF≈0.003，1秒音频仅需 3ms），同时自然度追平（MOS≈4.6）。核心秘籍：Variance Adaptor 把时长、F0、能量这三个韵律方差显式预测并加到隐表征里。

🎼 Mini-FastSpeech2：FFT + Variance Adaptor

1原理图

2通俗原理

Tacotron 自回归一帧一帧念，像"用手指着字读"。FastSpeech 2 反其道而行：先决定每个字念几帧（时长），把每个字的"标签"复制成对应长度的"卡片"拼成一长条，再一次性并行算出所有帧。这就是非自回归，所以特别快。

但是直接把音素拉长成帧，韵律信息（音高起伏、音量大小）会丢。FastSpeech 2 加了三个"外挂"预测器：时长预测器预测每个音素多少帧、F0 预测器预测每帧的基频（音高曲线）、能量预测器预测每帧的能量（音量包络）。把 F0/能量投影成向量加到隐状态里，韵律就显式回来了。训练时，时长/F0/能量的"真值"从教师模型（Tacotron+MFA）+真实波形提取出来做监督，预测器用 MSE 训练。

3数学公式

$$H_{ph} = \mathrm{Enc}(\text{Phonemes}),\quad \hat{d}_p = \mathrm{Dur}(H_{ph}[p])$$ $$H_{\text{frame}} = \mathrm{LR}(H_{ph}, \hat{d}) = [h_1\!\times\!\hat{d}_1,\;h_2\!\times\!\hat{d}_2,\;\ldots,\;h_P\!\times\!\hat{d}_P]$$ $$\hat{f}_t = \mathrm{Pitch}(H_{\text{frame}}[t]),\;\;\hat{e}_t = \mathrm{Energy}(H_{\text{frame}}[t])$$ $$H'_{\text{frame}}[t] = H_{\text{frame}}[t] + W_f\hat{f}_t + W_e\hat{e}_t$$ $$\hat{M} = \mathrm{Dec}(H'_{\text{frame}})\quad\text{(一次性并行输出所有帧)}$$
符号说明：
H_ph音素级 Encoder 输出（长度 P）
d̂_p音素 p 预测帧数（对数域预测再 exp）
LR长度规整器：把音素级隐状态重复扩展到帧级
f̂_t, ê_t帧 t 预测的 F0（连续值）与能量
W_f, W_e把标量 F0/能量投影到隐维度的线性层
M输出 Mel 谱（长度 T=Σd̂_p）

# ============ Mini-FastSpeech2（PyTorch 简化版） ============
import torch, torch.nn as nn, torch.nn.functional as F

class FFTBlock(nn.Module):
    # 简化 FFT Block：Conv1d + LN + 残差（省略自注意力，用大核 Conv 近似局部依赖）
    def __init__(self, dim, kernel=9):
        super().__init__()
        self.conv1 = nn.Conv1d(dim, dim*4, kernel, padding=kernel//2)
        self.conv2 = nn.Conv1d(dim*4, dim, kernel, padding=kernel//2)
        self.ln1 = nn.LayerNorm(dim); self.ln2 = nn.LayerNorm(dim)
    def forward(self, x):         # x: [B,T,D]
        y = self.ln1(x)
        y = self.conv2(F.gelu(self.conv1(y.transpose(-1,-2)))).transpose(-1,-2)
        return self.ln2(x + y)

class VarPredictor(nn.Module):
    def __init__(self, dim):
        super().__init__()
        self.net = nn.Sequential(
            nn.Conv1d(dim,dim,3,padding=1),nn.ReLU(),nn.LayerNorm([dim]),
            nn.Conv1d(dim,dim,3,padding=1),nn.ReLU(),nn.LayerNorm([dim]),
            nn.Conv1d(dim,1,1))
    def forward(self, x):       # [B,T,D] -> [B,T]
        return self.net(x.transpose(-1,-2)).squeeze(1)

class MiniFastSpeech2(nn.Module):
    def __init__(self, n_vocab=50, dim=128, mel_dim=80, n_layers=4):
        super().__init__()
        self.emb = nn.Embedding(n_vocab, dim)
        self.enc = nn.Sequential(*[FFTBlock(dim) for _ in range(n_layers)])
        self.dur_pred = VarPredictor(dim)
        self.f0_pred  = VarPredictor(dim)
        self.energy_pred = VarPredictor(dim)
        self.f0_proj = nn.Linear(1, dim); self.e_proj = nn.Linear(1, dim)
        self.dec = nn.Sequential(*[FFTBlock(dim) for _ in range(n_layers)])
        self.out = nn.Linear(dim, mel_dim)

    def length_regulate(self, h, d):
        # h:[B,P,D], d:[B,P] 整数帧数，用 repeat_interleave 手搓扩展
        out = []
        for b in range(h.size(0)):
            reps = d[b].clamp(min=1).long().tolist()
            out.append(torch.repeat_interleave(h[b], torch.tensor(reps,device=h.device), dim=0))
        return torch.nn.utils.rnn.pad_sequence(out, batch_first=True)

    def forward(self, tokens, durations=None):
        h = self.enc(self.emb(tokens))
        log_dur = self.dur_pred(h)
        if durations is None:
            d = torch.clamp(torch.round(torch.exp(log_dur)-1).long(), min=1)
        else:
            d = durations.long()
        hf = self.length_regulate(h, d)
        f0 = self.f0_pred(hf); e = self.energy_pred(hf)
        hf = hf + self.f0_proj(f0.unsqueeze(-1)) + self.e_proj(e.unsqueeze(-1))
        mel = self.out(self.dec(hf))
        return mel, log_dur, f0, e

m = MiniFastSpeech2(); m.eval()
tokens = torch.randint(0,50,(1,20))
durs   = torch.randint(3,12,(1,20))
with torch.no_grad():
    mel, log_dur, f0, e = m(tokens, durs)
print("mel:", mel.shape, "总帧数:", durs.sum().item())

🔥 HiFi-GAN · 工业级 GAN 声码器之王

HiFi-GAN（Kong et al., 2020）是目前工业界最常用的神经声码器，兼顾速度与音质（MOS≈4.4、GPU RTF≈0.003）。核心创新：多感受野融合（MRF）——用多组不同 kernel + dilation 的残差块并联，让模型同时看大尺度包络与小尺度细节。

🎛️ HiFi-GAN 生成器：上采样 + 多感受野残差块

1原理图

2通俗原理

波形的生成像"搭金字塔"：先粗后细。输入的 Mel 谱是低时间分辨率的（100帧/秒），要生成波形（22050采样点/秒），需要 220× 上采样——HiFi-GAN 用4 个转置卷积逐级放大（8×8×2×2 = 256×，接近 hop_length=256）。

难点在于：同时看得到全局包络和局部脉冲。如果卷积核太小，看不到音素级别的起伏；如果太大，细节锯齿又处理不好。HiFi-GAN 的解法很妙——把 3 个不同 kernel（3/7/11）的 ResBlock 并联起来，每个 ResBlock 内部用 dilated conv 扩大感受野，最后把它们的输出加起来（MRF），这样模型既能听到元音那样的长结构，也能发出清脆的辅音脉冲。

对抗训练方面用两个判别器：MPD（Multi-Period Discriminator）把波形按不同周期折叠后看，能抓到周期性伪影；MSD（Multi-Scale Discriminator）在不同下采样尺度上看，兼顾长短期结构。生成器和判别器互相博弈，最终生成的波形 MOS 可达 4.4+。

3数学公式

$$G(s) = \text{Tanh}\big(\text{Conv}(\text{MRF}_4(\text{Up}_4(\cdots\text{MRF}_1(\text{Up}_1(\text{Conv}(s))))))\big)$$ $$\text{MRF}(x) = \sum_{k} \frac{\text{ResBlock}_k(x)}{|\{k\}|}, \quad k\in\{3,7,11\}$$ $$\mathcal{L}_G = \sum_{k}\mathbb{E}\big[(D_k(G(s))-1)^2\big] + \lambda_{fm}\mathcal{L}_{fm}$$
符号说明：
s输入 Mel 谱 [B, 80, T']
Up_i第 i 个转置卷积上采样块
MRFMulti-Receptive-Field Fusion，多感受野融合
ResBlock_kkernel=k 的 dilated 残差卷积块
D_k第 k 个子判别器（MPD+MSD 共7个）
L_fm特征匹配损失（判别器中间特征 L1 距离）

4从零手搓（PyTorch 实现核心生成器）

# ============ HiFi-GAN 生成器核心（PyTorch 简化版） ============
import torch, torch.nn as nn, torch.nn.functional as F

class ResBlock(nn.Module):
    """单个 dilated 残差块：LeakyReLU → Conv(d) 串联 + 残差"""
    def __init__(self, ch, k=7, dilations=(1,3,5)):
        super().__init__()
        self.convs = nn.ModuleList()
        for d in dilations:
            self.convs.append(nn.Sequential(
                nn.LeakyReLU(0.1),
                nn.Conv1d(ch, ch, k, padding=d*(k//2), dilation=d)))
    def forward(self, x):
        for c in self.convs:
            x = x + c(x)         # 残差连接
        return x

class MRF(nn.Module):
    """多感受野融合：不同 kernel 的 ResBlock 并联，输出相加平均"""
    def __init__(self, ch, kr=(3,7,11)):
        super().__init__()
        self.blocks = nn.ModuleList([ResBlock(ch, k) for k in kr])
    def forward(self, x):
        return sum(b(x) for b in self.blocks) / len(self.blocks)

class HiFiGANGenerator(nn.Module):
    def __init__(self, mel_dim=80, ch=512,
                 ups=(8,8,2,2),     # 上采样倍率 ×256 = hop_length
                 ups_k=(16,16,4,4)):
        super().__init__()
        self.conv_pre = nn.Conv1d(mel_dim, ch, 7, padding=3)
        self.ups = nn.ModuleList()
        self.mrfs = nn.ModuleList()
        c = ch
        for u, uk in zip(ups, ups_k):
            c = c // 2
            self.ups.append(nn.ConvTranspose1d(c*2, c, uk, u, padding=uk//4))
            self.mrfs.append(MRF(c))
        self.conv_post = nn.Sequential(
            nn.LeakyReLU(0.1),
            nn.Conv1d(c, 1, 7, padding=3),
            nn.Tanh())                 # 输出限制在 [-1,1]
    def forward(self, mel):            # mel: [B,80,T']
        x = self.conv_pre(mel)
        for up, mrf in zip(self.ups, self.mrfs):
            x = F.leaky_relu(x, 0.1)
            x = up(x)                   # 时间轴放大 u 倍
            x = mrf(x)                  # 多感受野细化
        x = self.conv_post(x).squeeze(1) # [B, T_wav]
        return x

# 快速前向验证（不训练）
G = HiFiGANGenerator(); G.eval()
mel = torch.randn(1, 80, 100)    # 1 秒 Mel @ 100 帧/秒
with torch.no_grad():
    wav = G(mel)
print("输入 mel:", mel.shape, "→ 输出波形:", wav.shape)
# 预期: [1,25600] ≈ 256× 上采样

🎭 VITS · 端到端 TTS 的大一统（2021）

之前的 TTS 都是"两段式"：声学模型（文本→Mel）+ 声码器（Mel→波形），两段分开训练会有信息损失。VITS（Variational Inference with adversarial learning for end-to-end Speech Synthesis, Kim et al., 2021）把两段合在一起，用 VAE + Flow + GAN 端到端训练，输入文本直接输出波形，MOS 4.7 首次追平真人录音。

🔄 后验 Encoder

从真实波形提取 latent z，训练时给 VAE 作"答案"，推理时不用

🌊 Normalizing Flow

若干层仿射耦合流（Residual Coupling）把 z 和先验对齐，增强表达力

🎲 随机时长预测

用 MAS（Monotonic Alignment Search）自动学习对齐+DP，然后用流预测时长分布（比 FastSpeech 固定时长更自然）

🎤 解码器

本质是 HiFi-GAN 生成器，把 latent 直接转波形，判别器对抗训练

🧩 损失三合一

VAE 的 KL 散度 + GAN 对抗损失 + Mel 重建 L1 损失

🎯 优势

单模型端到端、MOS≈真人、支持 one-shot 音色克隆（VITS2/YourTTS）

📌现代 TTS 的研究主线（2023-2025）：VALL-E / SoundStorm / Voicebox / F5-TTS / CosyVoice / ChatTTS / MaskGCT 等，大多转向 离散 Token + 语言模型（LLM） 或 Flow Matching 范式，把 TTS 当"声音的 LLM"来做。但 Tacotron2/FastSpeech2/HiFi-GAN/VITS 这一套"两段式 + 端到端 + GAN"依然是工业部署与入门学习的核心。

📚 论文精读 · TTS 核心 8 篇

📘 WaveNet: A Generative Model for Raw Audio
van den Oord et al., DeepMind, 2016 · arXiv 1609.03499
第一个用神经网络直接生成原始音频波形，扩张因果卷积+softmax 分桶256值，MOS 4.2 远超之前所有参数合成，但自回归极慢，主要贡献是证明"神经生成音频可行"。
📗 Natural TTS Synthesis by Conditioning WaveNet on Mel Spectrogram Predictions (Tacotron 2)
Shen et al., Google, 2018 · ICASSP 2018
确立"声学模型(Tacotron2)+神经声码器(WaveNet)"两段式标准流水线；引入 Location-Sensitive Attention 保证对齐稳定；MOS 4.53 首次接近真人。
📕 FastSpeech: Fast, Robust and Controllable TTS
Ren et al., Microsoft, 2019 · NeurIPS 2019
第一个非自回归 TTS；用教师模型提取时长→长度调节器扩展音素到帧→并行生成 Mel；比 Tacotron2 快 270×，鲁棒性（不漏字重复）大幅提升。
📙 FastSpeech 2: Fast and High-Quality End-to-End TTS
Ren et al., Microsoft, 2020 · ICLR 2021
在 FastSpeech 基础上加入 Variance Adaptor，显式预测 F0/能量，去掉教师蒸馏，直接用 MFA 对齐训练；MOS 4.6，至今是工业部署首选。
📓 HiFi-GAN: Generative Adversarial Networks for Efficient and High Fidelity Speech Synthesis
Kong et al., Kakao, 2020 · NeurIPS 2020
提出 MRF 多感受野融合 + MPD+MSD 双判别器；RTF 0.003，MOS 4.4，成为至今最常用的神经声码器。
📔 VITS: Conditional Variational Autoencoder with Adversarial Learning for End-to-End TTS
Kim et al., Kakao, 2021 · ICML 2021
首个端到端单模型 TTS（文本→波形），VAE+Flow+GAN+MAS 四位一体，MOS 4.7 追平真人；开源后大量 follow-up（VITS2/YourTTS/StyleTTS 系列）。
📒 Neural Codec Language Models are Zero-Shot TTS (VALL-E)
Wang et al., Microsoft, 2023 · ICASSP 2024
把音频用 EnCodec 离散化成 Token（类似 BPE），用 GPT 式语言模型"续写音频"；3秒 prompt 即可克隆音色，开启"LLM for TTS"新范式。
📖 CosyVoice / F5-TTS / MaskGCT (2024-2025)
阿里/复旦/字节 等
中文零样本 TTS 最新代表；CosyVoice 做语义+流匹配双层次；F5-TTS 用 Diffusion Transformer 做 flow matching；MaskGCT 用全非自回归掩码预测，速度和质量都达SOTA。

🕸️ 知识本体 Schema

TTS 领域的核心概念本体（Concept Graph）：

TextToSpeech
├─ 前端 Text Frontend
│   ├─ 文本正则化 (TN)
│   ├─ 分词 / G2P（字→音素）
│   ├─ 韵律预测（停顿/重音）
│   └─ 多音字消歧
├─ 信号基础
│   ├─ 源-滤波模型（声源 + 声道）
│   ├─ 基频 F0（YIN/PYIN/Harvest）
│   ├─ 共振峰（LPC/LSP）
│   └─ STFT/Mel 谱
├─ 声学模型（Text→声学特征）
│   ├─ 统计参数：HTS/STRAIGHT/WORLD
│   ├─ 自回归：Tacotron2/DeepVoice3
│   ├─ 非自回归：FastSpeech2/VITS(部分)
│   └─ LLM范式：VALL-E/SoundStorm/CosyVoice
├─ 声码器（声学特征→波形）
│   ├─ 相位重建：Griffin-Lim
│   ├─ 参数：WORLD
│   ├─ AR神经：WaveNet/WaveRNN
│   ├─ GAN：MelGAN/HiFi-GAN/BigVGAN
│   ├─ Flow：WaveGlow
│   └─ 端到端：VITS（含解码器）
├─ 关键问题
│   ├─ 时长对齐（Attention/MFA/LengthRegulator/MAS）
│   ├─ 韵律建模（F0/能量/风格/GST）
│   ├─ 多说话人/零样本克隆（X-vector/UTT-Embed）
│   └─ 情感/可控性
└─ 评价
    ├─ MOS（主观平均意见分）
    ├─ MCD（Mel 倒谱失真）
    ├─ F0 RMSE
    └─ DNSMOS/UTMOS（客观神经指标）
