📢 TTS 语音合成

语音合成（Text to Speech，TTS）是将文本转换为自然人类语音的技术。从早期机械合成到现在的神经语音克隆，TTS的自然度已经接近甚至在某些场景超过真人水平。

💡 通俗理解

TTS 就像给计算机装了"嘴巴"。ASR是"听写员"把声音变成文字，TTS则是"播音员"把文字念出来。但要念得自然并不容易—— 不仅要发音准确，还要掌握停顿、语调、重音、情感，甚至呼吸声，才能让人听起来像真人在说话，而不是机器人。

🎤
学完「朗读」还想学「听写」？
TTS 是说（文本→声音），ASR 是听（声音→文本），二者共享声学特征与神经网络基础，构成语音技术的完整闭环。

⭐ 如何评估TTS质量：MOS分

TTS最核心的主观评价指标是MOS（Mean Opinion Score，平均意见分），由人类听音员对合成语音的自然度打分。

MOS分质量等级说明
5优秀与真人无法区分
4良好自然流畅，偶有小瑕疵
3一般可懂但明显机器感
2较差部分听不清，机器感重
1很差不可理解

真人自然语音的MOS约为4.7-4.8。当前最优的神经网络TTS系统MOS已可达4.6-4.7，基本与真人难以区分。

其他常用客观指标

  • MCD (Mel Cepstral Distortion)：梅尔倒谱失真，衡量合成语音与真实语音在倒谱域的距离，越低越好
  • F0 RMSE：基频预测误差，衡量韵律准确度
  • 说话人相似度：用说话人验证模型(如ECAPA-TDNN)提取嵌入，计算余弦相似度
  • CMOS (Comparison MOS)：成对比较MOS，A/B测试更稳定
  • WER (用于反向ASR验证)：合成语音被ASR识别的字错率，可懂度的客观代理指标

📅 技术发展简史

1939 VODER 机械合成器

贝尔实验室Homer Dudley制作，需要操作员按键控制发音，是第一个电子语音合成器。

1960s-80s 共振峰合成 / 拼接合成萌芽

基于源-滤波器理论的共振峰合成（Klatt合成器）流行，能合成可懂度尚可的语音，但非常机械。

1990s 大语料库单元拼接合成

从大量真人录音中挑选单元拼接，自然度大幅提升，是商用系统（如早期Siri）的基础。

2000s HMM统计参数合成(HTS)

基于HMM的参数合成，灵活性强（可变声、变速），但有过平滑问题，声音发闷。

2016 WaveNet 神经声码器革命

DeepMind WaveNet首次证明神经网络可以生成高保真语音波形，MOS首次接近真人。

2017-2018 端到端TTS：Tacotron2

Google Tacotron2首次实现端到端文本→梅尔谱，结合WaveNet生成语音，MOS达4.53。

2019-2020 非自回归时代

FastSpeech、ParaNet实现并行解码，速度大幅提升；HiFi-GAN等GAN声码器实现实时高保真。

2021-至今 端到端+大模型+零样本克隆

VITS统一框架实现完全端到端；VALL-E实现3秒零样本语音克隆；大模型驱动的对话TTS(ChatTTS)涌现。

📝 文本前端：TTS的"大脑"

直接把字符送进神经网络是不行的——文本有数字、缩写、多音字、特殊符号，还需要预测在哪里停顿、哪个字重读。文本前端就是做这些"文本规范化"工作。

输入文本 ↓ [1] 文本归一化 (Text Normalization) 数字、日期、金额、缩写 → 文字 ↓ [2] 分词 / 词性标注 / 多音字消歧 ↓ [3] 字音转换 (G2P: Grapheme-to-Phoneme) 汉字/字符 → 音素序列(带声调) ↓ [4] 韵律预测 (Prosody Prediction) 停顿位置、停顿时长、重音、语调 ↓ 语言学特征 (音素+韵律标注) ↓ 送入声学模型

1. 文本归一化 (TN)

把非标准文本转换为可朗读的标准文字，这是TTS最繁琐但最关键的预处理步骤：

输入归一化输出说明
2024年二零二四年年份按位读
123元一百二十三元金额按数量读
3:15三点十五分 / 三点一刻时间两种读法
90%百分之九十百分号展开
Mr. Smithmister smith缩写展开
No.1number one缩写展开
189cm一百八十九厘米单位展开

2. 字音转换 (G2P)

将文字（grapheme）转换为发音音素（phoneme）序列，中文还需要解决多音字问题：

  • 英文：字母到发音的映射非常不规则（如read/read、lead/lead），常用字词典+LSTM/Transformer G2P模型处理集外词
  • 中文：汉字带声调，例如"你好"→n i3 h au3；最大难点是多音字消歧（"银行"vs"行走"、"重量"vs"重复"、"音乐"vs"快乐"）
  • 目前主流TTS模型直接用字符作为输入，让模型隐式学习G2P，但前端G2P仍然能显著提升生僻字和多音字准确率

3. 韵律预测

韵律（Prosody）就是说话的"节奏"——什么时候停、停多久、哪个字重读、语调升还是降。韵律自然不自然直接决定TTS是否听起来像真人。

🎵 韵律的重要性

如果把所有字都用同样的音高、同样的速度连续读出来，哪怕每个字发音再标准，听起来也像机器人，非常不自然。真人说话会在词间短暂停顿(#1)、短语间停顿(#2)、分句间停顿(#3)、句末停顿(#4)，并且通过音高变化表达疑问、陈述、感叹等语气。

中文韵律层级标注（TBL标准）

  • #0：无语停，字与字之间紧密连接
  • #1：词间短停 (~100ms)
  • #2：韵律词之间 (~200ms)
  • #3：韵律短语之间 (~300ms，通常伴随换气)
  • #4：句间停顿 (~400-500ms，语调下降)

🔬 源-滤波器模型：语音产生的物理模型

理解TTS绕不开源-滤波器模型（Source-Filter Model），这是1960年代Fant提出的语音产生经典理论：

┌─────────────┐ ┌─────────────┐ ┌─────────────┐ │ 激励源 e(n) │ ──→ │ 声道滤波器 V(z) │ ──→ │ 辐射特性 R(z) │ ──→ 语音 s(n) │ (声门脉冲/ │ │ (共振峰) │ │ (嘴唇辐射) │ │ 白噪声) │ │ │ │ │ └─────────────┘ └─────────────┘ └─────────────┘ 浊音: 周期脉冲串 (由基频F0控制周期) 清音: 随机白噪声

这个模型极其优美地解释了语音产生：激励源决定音高和清浊，声道滤波器决定音色（元音），二者独立控制。这就是为什么你可以用同一个声道形状（口型）唱出不同的音高，也可以用同一个音高发出不同元音。

浊音 (Voiced)

声带周期性振动产生，如元音/a/e/i/o/u/、鼻音m/n/l，时域呈周期性波形，频域有明显的谐波结构。

清音 (Unvoiced)

声带不振动，气流通过声道狭窄处产生湍流噪声，如s/sh/f/h，波形类似白噪声，无明显周期性。

🧩 单元拼接合成

拼接合成（Concatenative TTS）的思路非常直接：录大量真人语音，切成小单元，合成时挑选最合适的单元拼接起来。

  • 语料库：专业播音员录制几小时到几十小时语音，覆盖所有音素上下文
  • 单元选择：根据目标音素序列+韵律特征，从语料库中搜索最优单元序列（考虑目标代价+拼接代价）
  • 波形拼接：在拼接点做交叉淡入淡出，保证平滑过渡
✅ 优点 vs ❌ 缺点

优点：使用真人录音片段，自然度上限高，没有模型预测的"机械感"
缺点：需要超大语料库，无法改变音色/情感/风格，拼接点不连续时会有"咔哒"声，无法合成语料库外的韵律，构建新说话人成本极高（需重新录音）。

📊 统计参数合成 HTS

基于HMM的参数合成（HTS, HMM-based Speech Synthesis System）通过统计模型预测声学参数，再用声码器合成波形。

文本 → 前端特征 → HMM时序模型 → 声学参数(MCC+F0+BAP) → 声码器(WORLD/STRAIGHT) → 波形
  • 预测的参数包括：梅尔倒谱(MCC)、基频F0、非周期成分(BAP)
  • 决策树聚类上下文，支持说话人自适应、情感变换、语速调整
  • 最大问题：过平滑(Over-smoothing)，模型预测的参数过于平滑，丢失细节，声音发闷、"机器味"重，MOS通常只有3.5左右

🧠 声学模型：深度学习时代

神经网络声学模型的任务是：输入前端语言学特征（或直接输入字符序列），输出梅尔频谱图（Mel-spectrogram），再由声码器将梅尔谱转换成最终波形。

文本 → Encoder → (Attention对齐) → Decoder → 梅尔频谱 → 声码器 → 音频波形

声学模型分为两大阵营：自回归模型（逐帧生成，慢但效果好）和非自回归模型（并行生成，快且稳定）。

🔄 自回归 (Autoregressive)

逐帧生成，每一帧依赖之前生成的帧

  • • 代表：Tacotron2, DeepVoice3
  • • 优点：音质好、韵律自然
  • • 缺点：推理慢、容易丢字重复、难以稳定控制时长

⚡ 非自回归 (Non-AR)

一次性并行生成所有帧，时长显式预测

  • • 代表：FastSpeech2, ParaNet
  • • 优点：推理极快、鲁棒不重复、时长可控
  • • 缺点：音质略逊于自回归（但差距已很小）

📦 经典模型：Tacotron2

2017 Tacotron 2 (Google)
Seq2Seq 自回归

Tacotron2是第一个真正实现"自然度媲美真人"的端到端TTS系统，MOS达到4.53（真人基准4.58），是TTS领域里程碑式的工作。

架构组成

  1. Encoder：字符嵌入 → 3层1D卷积 → BiLSTM，编码字符序列
  2. Attention：Location-Sensitive Attention，加入累积位置权重解决重复/漏字问题
  3. Decoder：2层LSTM自回归生成，每帧预测一帧80维梅尔谱，同时预测停止token判断是否结束
  4. Post-Net：5层1D卷积，对预测的梅尔谱做残差修正，提升细节
  5. WaveNet声码器：将梅尔谱转换为最终波形
🎯 关键创新

Location-Sensitive Attention在注意力计算中加入之前注意力权重的累积，避免模型反复关注同一位置（重复字）或跳过某些位置（漏字），显著改善了端到端TTS的稳定性。

📦 经典模型：FastSpeech 2

2020 FastSpeech 2 (Microsoft)
非自回归 并行生成

FastSpeech2是非自回归TTS的代表作，解决了Tacotron2自回归慢、不稳定的问题，是工业界部署的主流选择。

核心思想

  • 显式时长预测：用时长预测器(Duration Predictor)预测每个音素对应多少帧，通过长度调节器(Length Regulator)扩展音素序列到帧级别
  • 更多方差信息：除时长外，显式预测基频F0（连续+V/UV决策）和能量(Energy)，提升韵律表现力
  • 前馈Transformer(FFT Block)：编码器和解码器都是纯Transformer的自注意力+1D卷积结构，完全并行计算
音素嵌入 ↓ ┌─────────────────────────────────────────┐ │ FFT Block × N (Encoder) │ └───────────┬─────────────────────────────┘ ↓ ┌───────────┴─────────────┐ │ 时长预测器 / F0预测器 │ ← 从教师模型对齐获取时长作为训练目标 │ / 能量预测器 │ └───────────┬─────────────┘ ↓ 长度调节器 (按预测时长扩展) ↓ ┌─────────────────────────┐ │ FFT Block × N (Decoder)│ └───────────┬─────────────┘ ↓ 梅尔频谱输出
⚡ 性能对比

FastSpeech2在音质与Tacotron2相当（MOS 4.48 vs 4.53）的前提下，推理速度提升270倍（GPU上0.04秒生成1秒语音），彻底解决了自回归模型难以实时部署的问题。

🎛️ 神经声码器：从频谱到波形

声码器（Vocoder）的任务是：将声学模型输出的梅尔频谱/声学特征，转换为最终的音频波形。声码器的质量直接决定合成语音的音质上限。

WaveNet：神经声码器的开山之作

DeepMind在2016年提出的WaveNet是首个能生成高保真语音的神经声码器，开创了神经声码器时代。

核心技术：因果空洞卷积 (Causal Dilated Convolution)

  • 自回归：逐采样点生成，每个点依赖之前所有点
  • 因果卷积：保证生成t时刻时看不到未来信息
  • 空洞卷积：卷积核步长指数增长，感受野呈指数级扩大，用很少层数就能覆盖几毫秒到几秒的上下文
  • 门控激活 + 残差连接：类似PixelCNN的门控残差块
  • μ律压缩：将16-bit采样压到256类做分类预测，更稳定

致命缺点：完全自回归逐采样点生成，生成1秒24kHz音频需要前向传播24000次，速度极慢，无法实时。因此WaveNet更多是作为"教师模型"生成训练目标，实际部署需要更快的声码器。

GAN声码器：HiFi-GAN 一统天下

基于GAN的声码器实现了高保真+实时推理的完美平衡，其中HiFi-GAN是目前工业界最主流的通用声码器。

2020 HiFi-GAN
Generative Adversarial Network

三大核心设计

  • 多感受野融合生成器：多尺度卷积核同时捕捉长周期（基频振动）和短周期（谐波细节）模式
  • 多周期判别器(MPD)：多个判别器分别看间隔1/2/3/5/7/11个采样点的采样，捕捉不同周期的周期性结构
  • 多尺度判别器(MSD)：对原始波形、2倍下采样、4倍下采样三个尺度做判别，捕捉不同尺度特征

损失函数组合

$$ \mathcal{L}_G = \lambda_{adv}\mathcal{L}_{adv} + \lambda_{fm}\mathcal{L}_{fm} + \lambda_{mel}\mathcal{L}_{mel} $$

对抗损失+特征匹配损失+梅尔谱重构损失三者结合

🌟 为什么HiFi-GAN这么成功？

MOS达到4.4以上，与WaveNet相当；完全并行，GPU上比实时快1000倍以上，CPU上也能实时；对不同说话人、不同梅尔谱生成模型泛化性好，几乎是"万能声码器"。目前大部分开源TTS项目默认使用HiFi-GAN。

🎭 VITS：端到端TTS的统一者

2021 VITS (Conditional VAE + GAN)
完全端到端

VITS (Variational Inference with adversarial learning for end-to-end Text-to-Speech) 是TTS领域的集大成之作，它首次把文本前端→声学模型→声码器整个流水线统一到一个端到端模型中，直接从文本生成波形，不再需要两阶段训练。

关键创新

  • 条件VAE架构：用变分自编码器将文本到波形建模为隐变量生成问题
  • 归一化流(Flow)：通过单调对齐搜索(MAS)做对齐，比注意力更稳定
  • 对抗训练：在波形域引入多周期判别器，直接端到端优化感知质量
  • 随机时长建模：预测时长分布而非确定值，合成语音有自然的时长变化（不会每次都一模一样）
✨ VITS的优势

两阶段TTS（声学模型+声码器）存在信息损失（梅尔谱丢失相位信息）和分布不匹配问题。VITS直接端到端训练波形，音质比Tacotron2+HiFi-GAN更好；同时支持随机采样，同一文本多次合成结果略有不同（真人说话每次也不一样），自然度更高。VITS是当前开源TTS的SOTA基础框架。

🔮 VALL-E：零样本语音克隆

2023 VALL-E (Microsoft)
语言模型式TTS

VALL-E标志着TTS正式进入大模型时代。它完全抛弃了之前的TTS架构思路，把语音合成就当做"音频语言模型"来做，和GPT生成文本的方式一样。

核心思想

  • 音频Tokenizer：用神经音频编解码器(EnCodec)将语音量化为离散token序列（类似"文字"）
  • 第一阶段：给定文本和3秒prompt，自回归生成声学token（决定内容和说话人音色）
  • 第二阶段：用非自回归模型生成细粒度声学code
  • 解码：用EnCodec解码器将离散token解码回波形
🚀 零样本克隆能力

VALL-E只需要3秒的说话人录音（prompt），就能克隆出该说话人的音色，并且可以生成任意文本的语音，连说话人的语气、情感、背景环境都能保持。它在6万小时（后来VALL-E X是7万+小时多语言）语料上训练，涌现出了之前TTS系统完全不具备的上下文学习能力。

💬 ChatTTS：对话式TTS新范式

2024 ChatTTS
专为对话场景优化

ChatTTS是2024年开源的对话式TTS模型，专门为LLM对话场景优化，是目前最"像真人聊天"的开源TTS之一。

  • 自然口语化：训练数据包含大量真实对话，会自然添加笑声、停顿、语气词、呼吸声
  • 细粒度韵律控制：通过特殊token控制笑声[uv_break]、停顿[lbreak]、叹气等口语现象
  • 多说话人：内置说话人embedding，支持切换不同音色
  • 非自回归架构：基于LLaMA-style Transformer，推理速度快
  • 中文为主：中英文双语，中文效果特别出色
