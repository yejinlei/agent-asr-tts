1. Connectionist Temporal Classification: Labelling Unsegmented Sequence Data with Recurrent Neural Networks (2006)

ASR ICML 2006 引用 ~15000+ Alex Graves et al. (IDSIA)
引入 CTC 损失函数，让 RNN 无需帧级对齐标签即可端到端训练，直接从未分段序列（语音）输出标签序列（文字），是端到端 ASR 的基石。

在 CTC 之前，ASR 必须用 HMM 做帧级强制对齐——训练流程繁琐（GMM-HMM → DNN-HMM 级联），需要发音词典、强制对齐、分割等多步手工流水线。

核心矛盾：输入语音帧序列长度 T 远大于输出标签序列长度 U（如 100 帧→10个字），且不知道每个字对应哪几帧。RNN 每帧输出一个字符，但没有帧级标签就无法直接做交叉熵。

CTC 引入空白符 blank (∅) 作为"间隔/重复"标记，把"对齐"问题转化为"对所有合法对齐路径求和"的可微分计算——前向-后向算法动态规划。

⚠️ 常见误区："CTC 不要求单调性、可以任意对齐"——错！CTC 天然单调（路径只能前进或停留），且无条件依赖（帧间输出独立），因此无法建模语言模型依赖，必须外接 LM 解码。
p(π | x) = ∏_{t=1}^{T} y_{t,π_t}
路径概率：每条对齐路径 π 的概率是各时刻 softmax 输出的乘积（条件独立假设——帧间独立）。
p(l | x) = Σ_{π ∈ B⁻¹(l)} p(π | x)
CTC 目标：对所有经过 B（去空白、合并重复）之后得到标签串 l 的路径 π 求和。B⁻¹(l) 是 l 的原像集合。
α(t,u) = (α(t-1,u) + α(t-1,u-1) + α(t-1,u-2)·I(l_u≠l_{u-2})) · y_{t,l'_u}
前向递推（DP）：α(t,u) 是 t 时刻到达标签序列扩展版 l'（插入∅）第 u 位的概率；三项分别对应 stay/从u-1跳/从u-2跳（字符相同则禁用第三项）。这就是 CTC 能 O(T·U) 计算的核心。

关键结论：CTC 在完全没有帧级标签的条件下达到甚至超过了 HMM 流水线，证明端到端对齐是可行的。

1. 范式革命：首次证明"无需分段/对齐"就能训练序列到序列模型，直接催生了端到端 ASR（之后的 LAS、RNN-T、Conformer 都共享同一目标变量定义）。

2. 可微分对齐：前向-后向 DP 让"对所有对齐求和"变得可计算、可微分、可 GPU 加速，这是工程可落地的关键。

3. 影响力扩散：CTC 被广泛应用到 OCR、手写识别、手势识别、语音活动检测等所有"输入比输出长、且天然单调对齐"的任务。

⚠️ 常见误区 1："CTC 不能建模输出间依赖所以过时了"——错！2020年后的 CTC + Self-Attention（Conformer-CTC、Wav2Vec2-CTC）依然是工业主流，它并行计算快、流式部署友好，且 beam search + LM 能有效弥补条件独立假设。
⚠️ 常见误区 2："blank 就是静音"——错！blank 仅表示"此处不输出新字符"，它可以覆盖发音段、重复字符内部，并不等同于物理静音。
# 极简 CTC 前向算法（NumPy）
import numpy as np

def ctc_forward(y, labels, blank=0):
    """y: (T, C) 每帧 softmax 概率；labels: 标签序列（不含 blank）"""
    T, C = y.shape
    L = len(labels)
    # 扩展序列：在每个标签前后插入 blank
    z = [blank]
    for l in labels:
        z.extend([l, blank])
    S = len(z)  # = 2L+1
    α = np.zeros((T, S))
    α[0, 0] = y[0, z[0]]  # 起点：blank
    α[0, 1] = y[0, z[1]]  # 或第一个标签
    for t in range(1, T):
        for s in range(S):
            p = α[t-1, s] + α[t-1, s-1]
            if s >= 2 and z[s] != blank and z[s] != z[s-2]:
                p = p + α[t-1, s-2]
            α[t, s] = p * y[t, z[s]]
    return -np.log(α[T-1, S-1] + α[T-1, S-2])

# 测试：两帧两类 + blank，标签为[1]
y = np.array([[0.6,0.4],[0.6,0.4]])
print("CTC loss =", ctc_forward(y, [1]))  # ~ -ln(0.4*0.6 + 0.6*0.4 + 0.4*0.4)

2. Attention Is All You Need (2017)

ASRTTS NeurIPS 2017 引用 ~120000+ Vaswani et al. (Google Brain / Google Research / UToronto)
彻底抛弃 RNN/CNN，仅用自注意力机制 + 前馈网络构建序列到序列模型，实现并行训练与长程依赖建模，是 GPT/BERT/Whisper/FastSpeech 等所有后续语音/语言大模型的骨架。

RNN（LSTM/GRU）序列计算必须串行——第 t 步依赖 t-1 步的隐藏状态，无法并行，长序列梯度消失，训练慢；CNN 虽可并行但捕获长程依赖需要堆叠很多层，路径长度 O(n/k)。

核心创新：用"缩放点积注意力"让任意两个位置直接交互（路径长度 O(1)），用"多头注意力"让模型在不同子空间学习不同关系；用"位置编码"注入顺序信息（因为纯注意力是置换不变的）。

在语音领域，Transformer 直接催生了 Conformer、Whisper、FastSpeech 等——没有 Transformer 就没有今天的大模型语音。

⚠️ 常见误区："Transformer 就是 Self-Attention"——不完整。Transformer = Multi-Head Self/Cross Attention + Position-wise FFN（两层MLP + GELU） + Residual + LayerNorm + Positional Encoding。FFN 参数量通常占 2/3，去掉它注意力只是 token 混合器。
Attention(Q,K,V) = softmax( QKᵀ / √d_k ) · V
缩放点积注意力：Q(query)/K(key)/V(value) 分别是投影后的矩阵；除以 √d_k 是为了防止点积值过大导致 softmax 进入饱和区、梯度消失。
MultiHead(Q,K,V) = Concat(head₁,...,head_h) W^O，head_i = Attention(Q W_i^Q, K W_i^K, V W_i^V)
多头注意力：并行做 h 次（原文 h=8）注意力，每次投影到 d_k=d_v=d_model/h=64 维，让模型关注不同子空间的关系（语法/语义/位置等）。
PE(pos,2i) = sin(pos/10000^{2i/d})，PE(pos,2i+1) = cos(pos/10000^{2i/d})
正/余弦位置编码：用不同频率的正弦函数给每个位置注入唯一编码，使模型能推断相对位置（sin(pos+k) 可由 sin(pos) 和 cos(pos) 线性表示）。

1. 统一架构：编码器-解码器都是完全相同的模块堆叠，简单、规整、易扩展，成为"深度学习新的通用积木"。

2. 完美适配硬件：整句输入矩阵乘法一次算完，训练时 O(1) 序列步（对比 RNN 的 O(n) 串行），充分利用 GPU/TPU 并行——这是它能在工业界铺开的决定性因素。

3. 可缩放性（Scaling Law）：参数量/数据量增加，性能可预测地提升——这直接催生 BERT、GPT、T5、Whisper、ViT、Swin、Conformer 等几乎所有大模型。

⚠️ 常见误区："Self-Attention 复杂度 O(n²) 所以语音上没用"——错。语音下采样（卷积前端 + stride）后序列长度降到数百，O(n²) 完全可接受；Conformer、Whisper、Hubert 都是用 Transformer encoder + Conv 下采样打天下。
import torch, torch.nn.functional as F, math

def scaled_dot_product_attention(Q, K, V, mask=None):
    """Q,K,V: (B, h, n, d_k);  mask: (n,n) 因果掩码用"""
    d_k = Q.size(-1)
    scores = Q @ K.transpose(-2, -1) / math.sqrt(d_k)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, -1e9)
    attn = F.softmax(scores, dim=-1)
    return attn @ V

class MultiHeadAttention(torch.nn.Module):
    def __init__(self, d_model=512, n_heads=8):
        super().__init__()
        self.n_heads = n_heads; self.d_k = d_model // n_heads
        self.Wq = torch.nn.Linear(d_model, d_model)
        self.Wk = torch.nn.Linear(d_model, d_model)
        self.Wv = torch.nn.Linear(d_model, d_model)
        self.Wo = torch.nn.Linear(d_model, d_model)
    def forward(self, q, k, v, mask=None):
        B, n, _ = q.shape
        def proj(W, x): return W(x).view(B,-1,self.n_heads,self.d_k).transpose(1,2)
        out = scaled_dot_product_attention(proj(self.Wq,q),proj(self.Wk,k),proj(self.Wv,v),mask)
        return self.Wo(out.transpose(1,2).contiguous().view(B,n,-1))

3. Listen, Attend and Spell (2015)

ASR ICASSP 2016 (arXiv 2015) 引用 ~7500+ William Chan et al. (CMU / Google Brain)
首个真正"端到端"的 ASR 模型：用金字塔 BiLSTM（Listener）压缩声学特征，用 Attention-based LSTM（Speller）逐字符输出，无需 HMM/词典/对齐，真正实现"听一听再拼出来"。

CTC 虽然无需分段，但有条件独立假设（输出间无直接依赖），且训练-推理解码不一致（需要外接 LM）；传统 Attention Seq2Seq（Bahdanau 2014）在语音上直接用会遇到 T 过长（数百帧）导致注意力分散、训练不稳。

核心创新：

  • Listener（金字塔 BiLSTM）：通过时间维度拼接降采样（每层把时间减半），把 1000 帧压到 100 个高级声学表示（h 向量），既压缩冗余又缓解长序列注意力。
  • Speller（2层LSTM + Attention）：每步生成一个字符时，用 decoder 状态作为 query 去 listener 输出上做注意力加权，得到上下文向量再预测字符。
⚠️ 常见误区："LAS 就是 Seq2Seq"——关键在金字塔结构：pBiLSTM 把时间分辨率逐层降低，这是语音特有的设计（类似后来 Conformer 的 stride 卷积）；朴素 Seq2Seq 不做下采样在长语音上会崩。
h = Listen(x) （金字塔BiLSTM）
Listener：每层 pBiLSTM 把时间相邻两个输出拼接，h_i^l = BiLSTM([h_{2i}^{l-1}; h_{2i+1}^{l-1}])，时间分辨率逐层减半。
e_{t,u} = ⟨W s_t, V h_u⟩（或MLP score），α_t = softmax(e_t)，c_t = Σ_u α_{t,u} h_u
Attention：用 decoder 状态 s_t 作为 query 对所有 encoder 输出 h_u 打分得到注意力分布 α_t，加权求和得到上下文向量 c_t。
P(y|x) = ∏_t P(y_t | s_t, c_t, y_{<t})，其中 s_t = LSTMCell([emb(y_{t-1}); c_t], s_{t-1})
Speller：自回归生成——每步以"上一个字符的 embedding + 当前上下文向量"为输入，输出字符分布；天然建模输出间依赖。

1. 语音领域首个 Seq2Seq SOTA：证明 Attention-based Encoder-Decoder 可以在 ASR 上真的"听懂并拼出来"，催生了后来的 Espnet、Transformer-ASR 等。

2. 引入下采样思想：金字塔 BiLSTM 把"先压时间、再做注意力"的工程范式带入 ASR，被后续所有模型沿用（Conformer 的 stride conv、Whisper 的 conv 前端都是这个思路）。

3. 训练方式启发 RNN-T：LAS 与 CTC 的融合（attention+ctc joint training）成为后来 Espnet/WeNet 训练标配。

⚠️ 常见误区："LAS 不能流式"——原版确实不能（soft attention 需要全序列），但后来的 MoChA（Monotonic Chunkwise Attention）、Triggered Attention 等变体通过单调/分块注意力实现了流式推理，工业上仍大量使用。
import torch, torch.nn as nn, torch.nn.functional as F

class ContentAttention(nn.Module):
    def __init__(self, d_enc, d_dec):
        super().__init__()
        self.W = nn.Linear(d_dec, d_dec); self.V = nn.Linear(d_enc, d_dec)
        self.w = nn.Parameter(torch.randn(d_dec))
    def forward(self, s_t, h):
        # s_t: (B, d_dec);  h: (B, U, d_enc)
        e = torch.tanh(self.W(s_t).unsqueeze(1) + self.V(h)) # (B,U,d)
        attn = F.softmax(e @ self.w, dim=-1)              # (B,U)
        c = (attn.unsqueeze(-1) * h).sum(1)                 # (B,d_enc)
        return c, attn

class SpellerStep(nn.Module):
    def __init__(self, v_size, d_emb=256, d_h=512, d_enc=512):
        super().__init__()
        self.emb = nn.Embedding(v_size, d_emb)
        self.lstm = nn.LSTMCell(d_emb + d_enc, d_h)
        self.attn = ContentAttention(d_enc, d_h)
        self.out = nn.Linear(d_h, v_size)
    def forward(self, y_prev, s_prev, h):
        s, c = self.lstm(torch.cat([self.emb(y_prev), s_prev[0]],-1), s_prev)
        ctx, _ = self.attn(s, h)
        logits = self.out(s)
        return logits, (s, c)

4. Conformer: Convolution-augmented Transformer for Speech Recognition (2020)

ASR Interspeech 2020 引用 ~5500+ Anmol Gulati et al. (Google)
把 Self-Attention（全局建模）和 Depthwise Separable Convolution（局部特征提取）、FFN（通道混合）用 Macaron 结构组合，成为语音识别事实标准编码器。

Transformer 擅长全局依赖但局部相关性建模弱（每位置全连接太"疏"）；CNN 擅长局部平移不变但长程依赖要堆很多层。语音信号同时需要：① 局部形态（共振峰、音素过渡）② 全局依赖（跨词/长句指代、说话人特征）。

核心创新：Macaron 结构 + Conv Module

  • 每个 Conformer block：FFN（半个残差）→ MHSA → Conv Module → FFN（半个残差）→ LayerNorm。两个 FFN 各乘 0.5（"马卡龙"，像夹心饼干）。
  • Conv Module：Pointwise Conv（升维4倍）→ GLU 门控 → Depthwise Conv（kernel=15~32，因果/非因果）→ Swish → Pointwise Conv（降维）+ BN。专门提取局部声学模式。
  • MHSA 前加相对位置编码（Transducer-XL 风格），更好建模时序。
  • 前端用 stride=2 的 conv 把时间下采样 4 倍。
⚠️ 常见误区："Conformer = CNN + Transformer 拼一下"——不是。关键是顺序：FFN→Attn→Conv→FFN 半残差；Macaron 0.5 系数、Conv 模块里的 GLU 门控+depthwise 都是必要组件。随意调换顺序效果明显下降。
ConvModule(x) = x + PW·Swish·DW·GLU·PW(x)
卷积模块：第一层 Pointwise Conv 把通道升 2×，GLU 激活（门控）压回 1×，然后 Depthwise Conv（大 kernel 15~32）抓局部模式，Swish，再 PW 压回。带 BN 和 dropout。
x_{i+1} = x_i + ½ FFN(x_i) （Macaron 半残差）
Macaron 结构：原始 Transformer 一个 block 只有一个 FFN；Conformer 在 MHSA 前后各放一个 FFN，且都用 0.5 残差权重。作者从 FNet/Macaron Net 引入，让"通道混合"和"空间混合"平衡。
MHSA 中加入相对位置偏置 a_{ij} = (x_i W^Q)(x_j W^K + r_{i-j})^T / √d
相对位置编码：相对位置项 r_{i-j} 只依赖位置差而非绝对位置，对语音时序（说话速率变化）更鲁棒。

1. 统一"局部+全局"：DWConv（局部n-gram）+ MHSA（全局依赖）+ FFN（通道混合）——这是对语音信号"分层时间结构"最贴切的归纳偏置，比纯 Transformer 或纯 CNN 都准。

2. 工业落地标准：此后几乎所有商用 ASR（WeNet、FunASR、AssemblyAI、Meta MMS、Google USM、Whisper 的继任者）都用 Conformer 作为 encoder 骨架。

3. 流式友好：因果 Conv + chunk attention 可直接做流式（Emformer、Chunk Conformer），兼顾准确率与延迟。

⚠️ 常见误区："Conformer 已经被 Whisper 取代了"——错。Whisper 用的是纯 Transformer encoder-decoder，不是 Conformer；但大量后来工作（Faster-Whisper encoder 重参数化、SenseVoice、Paraformer）都是 Conformer 变种，Whisper 强在数据规模而非 encoder 结构。
import torch, torch.nn as nn, torch.nn.functional as F

class ConvModule(nn.Module):
    """Conformer Conv Module：PW→GLU→Depthwise→BN→Swish→PW"""
    def __init__(self, d, kernel_size=31, exp=2):
        super().__init__()
        self.pw1 = nn.Conv1d(d, d*exp, 1)
        self.pw1_gate = nn.Conv1d(d, d*exp, 1)
        # depthwise：groups=通道数
        self.dw = nn.Conv1d(d*exp, d*exp, kernel_size,
                         padding=(kernel_size-1)//2, groups=d*exp)
        self.bn = nn.BatchNorm1d(d*exp)
        self.pw2 = nn.Conv1d(d*exp, d, 1)
    def forward(self, x):
        # x: (B,T,d)
        y = x.transpose(1,2)
        y = F.silu(self.bn(self.dw(F.glu(torch.cat(
            [self.pw1(y), self.pw1_gate(y)],1), dim=1))))
        return x + self.pw2(y).transpose(1,2)

class FFNMacaron(nn.Module):
    def __init__(self, d, mult=4):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(d,d*mult), nn.SiLU(), nn.Dropout(0.1),
            nn.Linear(d*mult,d), nn.Dropout(0.1))
    def forward(self, x): return 0.5 * self.net(x)  # ½ 系数

ASR ICML 2023 (arXiv 2022) 引用 ~12000+ Alec Radford et al. (OpenAI)
用 68万小时弱标注互联网音频训练一个大规模 Transformer Encoder-Decoder，统一多语言 ASR + 翻译 + 语言识别 + 时间戳，零样本迁移到多数 benchmark 即接近或超过监督 SOTA。

⚠️ 常见误区 2："Whisper 开源了训练代码/数据"——只开源了模型权重和推理代码，数据过滤流水线未开源，训练超参未完全披露（这也是 "weak supervision" 论文能成为工业标杆的特殊案例）。

import torch

def whisper_decode(mel, encoder, decoder, tokenizer,
                  lang="zh", task="transcribe", timestamps=False):
    """mel: (1,80,3000); 模拟 30s log-mel"""
    enc_out = encoder(mel)  # (1,750,d)
    # 构造 prompt 前缀
    sot = tokenizer.encode("<|startoftranscript|>")
    toks = sot + [tokenizer.lang_to_id(lang),
                  tokenizer.token_to_id(f"<|{task}|>"),
                  tokenizer.token_to_id(
                      "<|timestamps|>" if timestamps else "<|notimestamps|>")]
    for _ in range(448):
        logits = decoder(torch.tensor([toks]), enc_out)[:, -1]
        nxt = logits.argmax(-1).item()
        if nxt == tokenizer.eot: break
        toks.append(nxt)
    return tokenizer.decode(toks[len(sot)+2+1:])

6. WaveNet: A Generative Model for Raw Audio (2016)

声码器 SSW 2016 (arXiv 2016) 引用 ~10000+ Aäron van den Oord et al. (DeepMind / Google)
首个能生成接近人类自然度语音的神经音频生成模型：用扩张因果卷积（dilated causal conv）直接建模原始波形 16kHz 样本点的自回归分布，证明神经网络可以合成高质量语音/音乐。

在 WaveNet 之前，语音合成要么是"拼接式"（录大量语料拼接），要么是基于信号处理的声码器（STRAIGHT/Griffin-Lim + 简单参数模型）——无法产生自然波形，声音机械。而 16kHz 波形每秒 16000 个点，直接用 RNN 自回归会太慢、LSTM 长程记忆也抓不住长结构。

核心创新：

  • 因果卷积（Causal Conv）：t 时刻只看 t 及之前的点，保证自回归不泄露未来。
  • 扩张卷积（Dilated Conv）：卷积核间隔按 2 的幂次扩张（1,2,4,8,...,512），堆叠几层感受野即可指数级扩大到上千点（几十毫秒），无需很深也无需 RNN。
  • 门控激活 + 残差 + skip：类 LSTM 门控，每一层都加一条 skip 连接到最终输出，类似 PixelCNN。
  • μ-law 压扩 256 类 Softmax：把 16-bit 样本 μ-law 压缩到 256 个 bin 做分类，比 MSE 回归稳定得多。
⚠️ 常见误区："WaveNet 是 TTS 模型"——错！WaveNet 是声码器/音频生成模型，本身不知道说什么内容，必须条件在语言学特征/梅尔谱（Tacotron2 将其作为 vocoder）；原版 WaveNet 直接自回归 16kHz 点，极慢（比实时慢 10-100 倍），无法实时部署。
p(x) = ∏_{t=1}^{T} p(x_t | x₁,...,x_{t-1}, h)
自回归因子分解：对每个波形点 x_t，用之前所有点 + 条件 h（如语言学/梅尔谱）预测 256 类概率。
z = tanh(W_{f,k} * x) ⊙ σ(W_{g,k} * x + V_{g,k}^T h)
门控激活单元（Gated Activation）：每一层 dilated causal conv 分两路——filter（tanh）和 gate（sigmoid），逐元素相乘；条件 h 通过 1×1 映射后加到 gate 支路，实现全局条件控制（说什么、谁在说）。
F(x_t) = sign(x_t) · ln(1+μ|x_t|) / ln(1+μ), μ=255
μ-law 压扩：把 16-bit 波形非线性压到 [-1,1] 后量化为 256 个整数，相当于对小幅值（低幅辅音/环境声）分配更多 bin——用 256 类分类就近似建模连续分布，比直接 Gaussian/MSE 稳定得多。

3. 开创神经声码器时代：之后 Tacotron2/WaveGlow/HiFi-GAN/BigVGAN 所有现代 TTS 的"波形后端"都直接建立在 WaveNet 的思想之上。

⚠️ 常见误区："WaveNet 被 Parallel WaveNet/WaveGlow 取代了所以已死"——不，它是所有神经声码器的老师。Parallel WaveNet / WaveFlow / WaveGrad 都是用 IAF/扩散把 WaveNet 的知识蒸馏到并行模型；HiFi-GAN 的 MRF 多感受野模块本质也是 dilated conv stack。
import torch, torch.nn as nn, torch.nn.functional as F

class CausalDilatedConv(nn.Module):
    """WaveNet 单层：causal + dilated + gated + 1×1 残差/skip"""
    def __init__(self, cin, cout, dilation):
        super().__init__()
        self.dil = dilation; r = dilation
        # left pad r 保证因果，kernel=2
        self.conv_f = nn.Conv1d(cin, cout, 2, padding=r, dilation=r)
        self.conv_g = nn.Conv1d(cin, cout, 2, padding=r, dilation=r)
        self.conv_cond = nn.Conv1d(cin, cout, 1)  # 条件 h
        self.res_proj  = nn.Conv1d(cout, cin, 1)
        self.skip_proj = nn.Conv1d(cout, cin, 1)
    def forward(self, x, h):
        # x: (B,C,T); 因果：裁剪掉右侧 padding 导致的"未来"值
        f = self.conv_f(x)[:, :, :-self.dil]
        g = self.conv_g(x)[:, :, :-self.dil] + self.conv_cond(h)[:, :, :x.size(-1)]
        z = torch.tanh(f) * torch.sigmoid(g)
        res  = self.res_proj(z) + x[:, :, :z.size(-1)]
        skip = self.skip_proj(z)
        return res, skip

7. Natural TTS Synthesis by Conditioning WaveNet on Mel Spectrogram Predictions (2017)

TTS ICASSP 2018 (arXiv 2017) 引用 ~9000+ Jonathan Shen et al. (Google)
把"字符→梅尔谱"的 Seq2Seq 注意力模型和"梅尔谱→波形"的 WaveNet 声码器串联，首次实现 MOS 4.53、与真人录音差距 0.02 的端到端 TTS，确立现代 TTS"前端+声码器"两阶段范式。

Tacotron 1 用 CBHG + Grffin-Lim 重建波形，Griffin-Lim 相位估计带来"金属质感"和伪影；原始 WaveNet 需要语言学特征（音素/时长/F0）作为条件输入，要单独训练时长/F0模型，流水线长。

核心洞察：

  • 梅尔谱作为中介表示：梅尔谱是音频的紧凑时频表示，丢掉相位但保留全部感知相关信息；用梅尔谱而不是语言学特征条件 WaveNet，既简化流程又提高自然度。
  • Location-Sensitive Attention：在 Bahdanau attention 基础上加入累积注意力权重作为额外特征——强制注意力"向前移动不回头"，解决语音合成中常见的丢字/重复/坍缩问题。
  • Encoder 用 3层卷积 + BiLSTM 处理字符；Decoder 是 2层LSTM 自回归逐帧生成 mel；Post-net（5层卷积）预测残差补偿频谱细节。
⚠️ 常见误区："Tacotron2 的创新是用 WaveNet"——错。真正关键是梅尔谱作为中间表征 + Location-Sensitive Attention + Post-net 残差预测，把"梅尔谱生成"做稳定了；WaveNet 只是后端声码器，后来都换成更快的 WaveGlow/HiFi-GAN。
e_{i,j} = wᵀ tanh(W s_i + V h_j + U f_{i,j} + b)
Location-Sensitive Attention 能量：在标准加性注意力基础上增加 U f_{i,j} 项，其中 f_{i,j} 是之前累积注意力权重 Σ_{k<i} α_{k,j} 经过卷积后的位置特征。这让当前对齐位置受历史对齐位置影响——强制"单调向前"，防止注意力回跳导致重复/漏字。
y_final = y_linear + PostNet(y_linear) （残差学习）
Post-Net 残差：decoder 先预测一个粗 mel（y_linear），再用 5 层卷积（含 tanh 最后一层线性）预测残差加到粗 mel 上，专门修正频谱细节（尤其是高频谐波），MOS 提升约 0.1。
损失 = MEL_MSE(y_linear, y*) + MEL_MSE(y_final, y*) + BCE(stop_tokens)
联合损失：同时监督粗 mel 和最终 mel；stop token 是二分类，告诉 decoder 什么时候停止生成（避免死循环或早停）。

1. 定义现代 TTS 标准范式："文本前端（字符/音素 encoder）→ 自回归 mel 生成（Seq2Seq+Attn）→ 神经声码器（WaveNet/HiFi-GAN）"——FastSpeech2/VITS 等后续所有 TTS 都沿用这个拆解。

2. 确立"梅尔谱作为中间表征"：比直接生成波形稳定，比语言学特征通用，梅尔谱成为 TTS 领域的"通用语"。

3. Location-sensitive attention 成为 TTS attention 标配：后续几乎所有自回归 TTS 都使用位置敏感/单调/动态卷积注意力来解决对齐稳定性。

⚠️ 常见误区："Tacotron2 不需要音素输入所以抛弃了语言学"——错。直接字符输入在英语这种拼音文字上可行，但中文/日文直接字符输入效果差，工业系统仍然用音素 + BERT prosody 前端；且 r=2~3 的帧步长减少解码步数是关键 trick。
import torch, torch.nn as nn, torch.nn.functional as F

class LocationSensitiveAttention(nn.Module):
    def __init__(self, d_enc=512, d_dec=1024, d_att=128, n_filters=32, k=31):
        super().__init__()
        self.W = nn.Linear(d_dec, d_att)
        self.V = nn.Linear(d_enc, d_att)
        self.F = nn.Conv1d(2, n_filters, k, padding=(k-1)//2, bias=False)
        self.U = nn.Linear(n_filters, d_att, bias=False)
        self.v = nn.Parameter(torch.randn(d_att))
    def forward(self, s_prev, h, alpha_prev, alpha_cum):
        # s_prev: (B,d_dec); h: (B,N,d_enc); alpha: (B,N)
        f = self.F(torch.stack([alpha_prev, alpha_cum],1)).transpose(1,2)
        e = torch.tanh(self.W(s_prev).unsqueeze(1) + self.V(h) + self.U(f))
        e = e @ self.v
        alpha = F.softmax(e, dim=-1)
        ctx = (alpha.unsqueeze(-1) * h).sum(1)
        return ctx, alpha

# Post-Net：5 层 Conv1D + BN + tanh，最后一层线性
class PostNet(nn.Module):
    def __init__(self, mel_dim=80, d=512, k=5, n=5):
        super().__init__()
        layers = []
        c_in = mel_dim
        for i in range(n-1):
            layers += [nn.Conv1d(c_in,d,k,padding=(k-1)//2), nn.BatchNorm1d(d), nn.Tanh(), nn.Dropout(0.5)]
            c_in = d
        layers += [nn.Conv1d(d,mel_dim,k,padding=(k-1)//2), nn.BatchNorm1d(mel_dim), nn.Dropout(0.5)]
        self.net = nn.Sequential(*layers)
    def forward(self, mel): return self.net(mel)

8. FastSpeech 2: Fast and High-Quality End-to-End Text to Speech (2020)

TTS ICLR 2021 (arXiv 2020) 引用 ~3500+ Yi Ren et al. (Microsoft Research)
抛弃自回归 attention，用基于时长预测的"前馈 Transformer"非自回归并行生成梅尔谱，同时显式预测 pitch/energy 方差信息，做到比 Tacotron2 快 200倍训练、100倍推理，质量不降反升。

FastSpeech 1 用"自回归教师模型的注意力对齐"做时长，存在 teacher-student 知识蒸馏误差（信息瓶颈），且只调节长度、没有韵律方差（pitch/energy），合成语音略"平"；Tacotron2 自回归逐帧生成慢（不能并行）、容易出现漏字/重复/attention 坍缩。

FastSpeech 2 核心改进：

  • 抛弃 teacher distillation：直接用 Montreal Force Alignment (MFA) 得到音素-帧的真实对齐时长，避免蒸馏损失。
  • 显式方差建模：除了时长（duration），还用独立预测器预测 pitch（F0 连续值，连续值小波分解或直接量化）和 energy（梅尔谱帧能量），把韵律信息直接条件到 encoder 输出。
  • 纯前馈 Transformer（FFT block）：和 Transformer 类似但 self-attention 后是 2 层 1D Conv（而非 Linear FFN），更适合时序；encoder 与 decoder 之间通过"长度规整（Length Regulator）"把音素序列按预测时长 expand 成帧级序列。
⚠️ 常见误区："FastSpeech 2 不需要对齐"——错！它的前提是用 MFA 预先做强制对齐得到 duration ground truth；相比 Tacotron2 自动学对齐，FastSpeech 是把对齐外置到数据预处理阶段，换取训练/推理稳定和并行速度。
H_phoneme = Encoder(phoneme_embed + PE)
音素编码：4 层 FFT Block（self-attn + 2层 Conv1D + 残差+LN），输出每个音素的语义表示。
d̂ = DurationPredictor(H_phoneme)， H_dur = LR(H_phoneme, d̂)
长度规整：Duration Predictor 预测每个音素持续多少帧（对数域 MSE 训练），Length Regulator 把第 i 个音素的 hidden 复制 d_i 份展开到帧级。
L = λ_mel · ||M - M̂|| + λ_dur · ||log d - log d̂||₁ + λ_pitch · ||p - p̂||₁ + λ_energy · ||e - ê||₁
多任务损失：mel L2 + duration L1（对数域）+ pitch L1（连续 F0 或量化 CE）+ energy L1。推理时所有 variance predictor 自包含，完全并行生成整段 mel，无自回归循环。

关键结论：Duration 解决长度，pitch 是韵律最关键的因素（+0.1 MOS），energy 补充能量维度让音色更饱满；pitch 用连续值回归比量化成 bin 做分类更好（避免 pitch 被量化成"阶梯"导致机械感）。

1. 非自回归 TTS 成为工业主流：FastSpeech 2 证明了"非自回归 + 显式韵律预测"不仅更快，而且比自回归更稳定（不坍缩/不重复/不跳字），成为工业部署 TTS 首选。

2. 显式方差建模思想：将 duration/pitch/energy 等语音学可解释变量解耦，后续 FastPitch、DiffSinger、RAD-TTS、NaturalSpeech 都沿用这套思路。

3. Length Regulator 范式："音素级编码→时长预测→展开到帧级→帧级解码"是后来所有并行 TTS 的经典范式，简单可解释且可控（直接缩放 d 就能调节语速）。

⚠️ 常见误区："FastSpeech 2 完全端到端不需要外部工具"——实际上需要MFA 做强制对齐获得训练用的 duration 标签；pitch 的提取用 PYIN/YIN 等传统 DSP。真正端到端不需要对齐的是 VITS（用 MAS 单调对齐搜索在线学习）。
import torch, torch.nn as nn

class VariancePredictor(nn.Module):
    """Duration / Pitch / Energy Predictor：同一个架构"""
    def __init__(self, d=256, d_inner=256, k=3, n=2, dropout=0.5):
        super().__init__()
        layers = []
        c_in = d
        for _ in range(n):
            layers += [nn.Conv1d(c_in,d_inner,k,padding=(k-1)//2),
                       nn.ReLU(), nn.LayerNorm(d_inner), nn.Dropout(dropout)]
            c_in = d_inner
        layers += [nn.Linear(d_inner,1)]
        self.net = nn.Sequential(*layers)
    def forward(self, x):
        # x: (B, T, d) -> (B, T)
        return self.net(x.transpose(1,2)).squeeze(-1)

def length_regulate(h, dur):
    """h: (B,N,d); dur: (B,N) 每个phoneme持续帧数（整数）→ (B,T,d)"""
    out = []
    for b in range(h.size(0)):
        segs = [h[b,i:i+1].expand(int(dur[b,i]),-1) for i in range(h.size(1)) if dur[b,i]>0]
        out.append(torch.cat(segs,0))
    return torch.nn.utils.rnn.pad_sequence(out, batch_first=True)

9. HiFi-GAN: Generative Adversarial Networks for Efficient and High Fidelity Speech Synthesis (2020)

声码器 NeurIPS 2020 引用 ~4000+ Jungil Kong et al. (Kakao Enterprise)
用 GAN 训练一个全卷积生成器（含多感受野融合 MRF 模块）+ 多周期/多尺度判别器（MPD+MSD），在 22kHz/44kHz 上生成音质超越 WaveNet 且能实时生成（GPU 上比实时快 100倍+），成为当前开源 TTS 标配声码器。

WaveNet 自回归太慢（不能实时）；Parallel WaveNet / WaveGlow 基于流（flow）需要教师模型蒸馏，训练复杂；MelGAN 虽然快但音质有明显伪影（发电机容量不足、判别器太弱）。

核心创新：

  • 生成器 G：转置卷积上采样（与 hop_length 匹配把 mel 上采样回采样率）+ 多感受野融合模块（MRF）——每个 MRF 里并行多个不同 kernel / dilation 组合的残差 dilated conv block，输出相加融合多周期特征。
  • 多周期判别器（MPD）：一组子判别器，各自只看波形的间隔为 [2,3,5,7,11] 的子采样，从而专门捕捉不同周期的谐波结构——这是 HiFi-GAN 音质飞跃的关键。
  • 多尺度判别器（MSD）：在原始波形、×½、×¼ 三个尺度上做判别，抓全局+局部。
  • 损失组合：GAN 损失 + Mel-Spectrogram 损失（频域 L1）+ Feature Matching 损失（判别器中间特征匹配），三管齐下。
⚠️ 常见误区："HiFi-GAN 就是个 GAN，把 mel 上采样成波形"——不，真正灵魂在 MPD（多周期判别器）：它让生成器必须把每个基音周期的谐波都还原好，否则在对应的子采样周期上会被判别器识破。没有 MPD，纯 MSD/MelGAN 都会在浊音段产生发闷/金属音。
G: mel (T,80) → wave (T·hop,), 通过 k 次 ConvTranspose1d(stride=k_i) 逐级上采样 + MRF 细化
Generator 上采样策略：上采样倍数乘积等于 hop_length（如 22050Hz, hop=256 → [8,8,2,2] 乘积 256），把时间长度恰好扩到波形长度，不需要额外插值。
MRF(x) = Σ_k ResBlock_k(x)，ResBlock 内是多 dilation 卷积分支残差加和
多感受野融合：k 个 ResBlock 并行，每个 block 内部有 dilations=[1,3,5]（或 [1,3]）的 dilated conv 残差栈，覆盖不同时间跨度，最后相加——让每个时间点同时看到短/中/长上下文。
L_G = Σ_{D∈{MPD,MSD}} [ (1-λ_fm) L_adv(G;D) + λ_fm L_fm(G;D) ] + λ_mel ||φ(real) - φ(fake)||₁
组合损失：对抗损失（哄过判别器）+ Feature Matching（匹配GT和假波形在判别器各层中间特征的L1，稳定训练）+ Mel-spectrogram L1 损失（φ 是 mel 变换，从频域保证声学相似度）。训练完 G 即可扔掉判别器，前向全卷积实时。

⚠️ 常见误区："HiFi-GAN V1 一定比 V2/V3 好"——V1/2/3 是不同容量配置：V1(80M参数, 高质量) / V2（MRF kernel/dil 较小，快）/ V3（更小、CPU 实时）；CPU/端侧部署选 V3/V2 更合适。此外通用版（UNIVERSAL_V1）能对未见 mel 分布直接泛化，但对训练域内专用模型稍差。
import torch, torch.nn as nn, torch.nn.functional as F

class ResBlock(nn.Module):
    """MRF 子 ResBlock：多层 dilated conv 残差"""
    def __init__(self, ch, k=3, dilations=(1,3,5)):
        super().__init__()
        self.convs = nn.ModuleList()
        self.convs_gate = nn.ModuleList()
        for d in dilations:
            p = (k-1)//2 * d
            self.convs.append(nn.Conv1d(ch,ch,k,1,p,dilation=d))
            self.convs_gate.append(nn.Conv1d(ch,ch,k,1,p,dilation=d))
    def forward(self, x):
        for c, g in zip(self.convs, self.convs_gate):
            r = torch.tanh(c(x)) * torch.sigmoid(g(x))  # gated
            x = x + r
        return x

class MRF(nn.Module):
    """多感受野融合：多个 ResBlock 输出相加"""
    def __init__(self, ch,
                 kernels=(3,7,11),
                 dils=((1,3,5),(1,3,5),(1,3,5))):
        super().__init__()
        self.blocks = nn.ModuleList([ResBlock(ch,k,d) for k,d in zip(kernels,dils)])
    def forward(self, x):
        return sum(b(x) for b in self.blocks) / len(self.blocks)

10. VITS: Conditional Variational Autoencoder with Adversarial Learning for End-to-End Text-to-Speech (2021)

TTS ICML 2021 引用 ~3000+ Jaehyeon Kim et al. (Kakao Enterprise)
把"文本→mel"和"mel→波形"两阶段合并为一个 VAE + GAN + Flow 的端到端模型，用单调对齐搜索（MAS）在线学对齐，直接从文本到波形单阶段训练，生成质量在单说话人/多说话人上达到两阶段流水线水平。

两阶段 TTS（Tacotron2/FS2 + HiFi-GAN）有两个问题：①两阶段分开训练，mel 是信息有损的中间表示（丢弃相位、过度平滑），声码器只能"猜"丢失信息；②FastSpeech2 需要外部对齐（MFA），Tacotron2 的 attention 在长句/少资源语言不稳。

VITS 核心创新：完全端到端 + VAE + MAS

  • Posterior Encoder：训练时从真实 mel 编码出 latent z（类似 VAE 后验）。
  • Text Encoder + Normalizing Flow（Residual Coupling Blocks）：预测 z 的先验分布——但先验在"音素级序列"上，而 z 是"帧级"。通过 MAS（Monotonic Alignment Search，单调对齐全局最优搜索）在两者之间找最优硬对齐。
  • Decoder：就是 HiFi-GAN 生成器（MRF + transconv upsample），直接从 z 出波形，而不是从 mel。
  • 判别器：复用 HiFi-GAN 的 MPD+MSD，加对抗损失让波形真实。
  • 损失 = VAE ELBO（重构 + KL）+ GAN 损失 + Feature Matching。
⚠️ 常见误区："VITS 完全不需要对齐"——它用 MAS（Monotonic Alignment Search）在线搜索最佳单调对齐，但 MAS 假设单调对齐且是 Viterbi 搜索；比起 MFA 独立预处理，VITS 把对齐整合进训练循环，但不是"无对齐"。
A* = argmax_{A∈𝓐} Σ_{n,t} A_{n,t} · log N(z_t; μ_n, σ_n²) （MAS）
单调对齐搜索：在所有单调非交叉对齐矩阵 A（A_{n,t}=1 表示第 n 个音素对齐第 t 帧）中找对数似然最大的——DP 在 O(N·T) 内完成。对齐每步更新，无需外部对齐器。
log p(x|c) ≥ E_{q(z|x)}[log p(x|z)] − KL(q(z|x) ‖ p(z|c,A)) （ELBO）
VAE 变分下界：Posterior encoder 编码真波形得到 q(z|x)（含相位等全部信息）；text encoder 经 flow + MAS 得到先验 p(z|c,A)。训练时最大化 ELBO：重构项让 decoder 还原波形，KL 项让先验逼近后验（推理时仅需先验采样）。
f_θ ← f_θ + Normalizing Flow，使 z = f_θ(z_0)，z_0 ~ N(μ_text, σ_text²)，|det ∂f/∂z_0| 可 O(D) 算
归一化流增强先验：简单 Gaussian 先验表达力不够，用残差耦合块（Residual Coupling Layers）的可逆流把简单高斯变换为更复杂的多模态分布——训练时反向运行（z→z_0）算 KL，推理时正向运行（z_0→z）采样出 latent。

⚠️ 常见误区："VITS 不需要声码器所以更快"——不是！VITS 的 decoder 就是 HiFi-GAN 生成器，本质上把声码器合并进模型里一起训，推理速度和单独 HiFi-GAN 同一量级；它快是因为少了"mel 自回归"的那一步（FastSpeech2 本身非自回归，所以 VITS 在速度上和 FS2+HiFi-GAN 相近，但质量更统一）。
import torch, torch.nn as nn, torch.nn.functional as F

def mas_search(log_p: torch.Tensor):
    """单调对齐搜索（DP）——极简版
    log_p: (N, T) 每对(n,t)的对数似然（来自 z_t 与 prior_n 的 -log NLL）
    返回: A (N,T) 0/1 对齐矩阵
    """
    N, T = log_p.shape
    Q = torch.full((N, T), -1e9)
    path = torch.zeros((N, T), dtype=torch.long)
    Q[0,0] = log_p[0,0]
    for t in range(1, T):
        Q[0,t] = Q[0,t-1] + log_p[0,t]; path[0,t] = 1
    for n in range(1, N):
        for t in range(n, T):
            # 单调：来自(n-1,t-1)走"对角线"或(n,t-1)走"stay"
            stay = Q[n,t-1]; move = Q[n-1,t-1]
            if stay > move: Q[n,t] = stay+log_p[n,t]; path[n,t] = 1
            else:           Q[n,t] = move+log_p[n,t]; path[n,t] = 0
    A = torch.zeros_like(log_p); n,t = N-1, T-1
    while n>=0 and t>=0:
        A[n,t]=1; n -= 1-path[n,t]; t -= 1
    return A

def kl_loss(z, mu_q, logvar_q, mu_p, logvar_p):
    """z~N(mu_q,var_q) 与 N(mu_p,var_p) 之间的 KL，每个样本"""
    return 0.5*(logvar_p - logvar_q
              + (logvar_q.exp()+(mu_q-mu_p).pow(2))/logvar_p.exp()
              - 1).sum(-1)
