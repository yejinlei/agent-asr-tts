# Agent-Speech: ASR & TTS 学习研究站

对标 [agent-cv](https://yejinlei.github.io/agent-cv/) 与 [agent-yolo](https://yejinlei.github.io/agent-yolo/) 风格构建的语音技术学习站点。

- **首页**：双轨导览 + 技术演进 + 学习路径 + 资源汇总
- **ASR 子站** (`asr/`)：从信号处理、MFCC、GMM-HMM 到 CTC/Attention/RNN-T/Conformer/Whisper
- **TTS 子站** (`tts/`)：从文本前端、源-滤波、拼接/参数合成到 Tacotron2/FastSpeech2/HiFi-GAN/VITS/VALL-E/ChatTTS

部署：所有文件为静态 HTML，直接推送到 GitHub Pages 根目录即可访问。
