🧠 变声的声学原理

📐 F0 与共振峰：声音的两个维度

声带振动 → F0（基频）
决定"音高"：成年男声 ≈ 85–180Hz，女声 ≈ 165–255Hz，童声 ≈ 250–400Hz。仅靠 F0 只能"变调"。
声道长度 → 共振峰（Formant）
声道是一根共振管：男性≈17cm、女性≈14cm、儿童≈10cm。管越短→共振峰频率整体越高，这才是"性别/年龄音色"的物理基础。

变调 ≠ 变声。简单把男声升 12 半音会得到"花栗鼠"（Alvin and the Chipmunks）——因为所有频率（包括共振峰）一起被拉高，声道也跟着"虚拟缩短"成不可能的尺寸。真正的变声（Voice Conversion）必须独立控制 F0 和共振峰：

操作F0共振峰听感
单纯变速一起变一起变快慢 + 花栗鼠
相声码器 pitch shift移位不变高低声（像同个人唱高音）
完整变声移位整体缩放真的像另一个人

本页通过「重采样+交叉淡化拼接」做 pitch shift 保持时长，用「biquad 高低 shelf 链」近似共振峰整体搬移——没有神经网络，但足以听出男/女/童/机器人/电话/水下的差异。

🔧 手搓核心：pitch shift 伪代码

基于重采样 + 帧交叉淡化的简化 SOLA 算法（相位声码器的时域近似，延迟低、实时友好）：

// ratio = 2^(semitones/12) ；升高音调→重采样后信号更长，要裁切回来 function pitchShift(buf, ratio, sr) { const frameSize = 2048, hop = 512; // 1. 把输入按 ratio 重采样：长度变为 n/ratio（升调变短、降调变长） const rs = resample(buf, sr, sr * ratio); const out = new Float32Array(buf.length); const win = hanning(frameSize); // 2. 以 hop 为步长加窗叠加，实现无缝拼接（OLA） for (let i=0, j=0; ifor (let k=0; kif (j+k < rs.length) out[i+k] += rs[j+k] * win[k]; } } // 3. 归一化、返回与输入等长的变调信号 return normalize(out); } // 共振峰尺度：频率轴 warp，用 highshelf/lowshelf 组合近似整体频谱包络搬移 // scale > 1 → 高频提升、低频切一点 → 更亮/更短声道（女/童） // scale < 1 → 高频切、低频抬 → 更闷/更长声道（男/老）

注：生产级变声用 WORLD / WORLD-vocoder 或神经声码器（HiFi-GAN + VC 模型）。这里为了零依赖、实时、零延迟，用了 O(1) 延迟的近似算法，足以演示原理并产生可辨的变声效果。
