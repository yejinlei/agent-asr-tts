🎤 ASR 语音识别

自动语音识别（Automatic Speech Recognition，ASR）是将人类语音中的词汇内容转换为计算机可读文本的技术。 它是语音交互、智能客服、实时字幕、会议记录等应用的核心技术基础。

💡 通俗理解

ASR 就像给计算机装了"耳朵"。想象一位专业的速记员：他听到你说话，把声音转换成文字记录下来。ASR 做的事情完全一样， 只不过这位"速记员"是由算法和神经网络构成的。它需要处理各种口音、背景噪音、语速变化，尽可能准确地"听写"出你说的每一个字。

📢
学完「听写」还想学「朗读」？
ASR 是听（声音→文本），TTS 是说（文本→声音），二者共享声学模型与神经网络基础，构成语音技术的完整闭环。

📅 技术发展简史

语音识别的研究已有超过70年历史，经历了数次范式转变，从模板匹配到统计建模，再到深度学习和大模型时代。

1952 Audrey系统

贝尔实验室开发，只能识别10个英文数字，是第一个可工作的语音识别系统。

1960s 动态时间规整(DTW)

解决不同语速下的语音匹配问题，模板匹配方法主导这一时期。

1980s GMM-HMM 范式确立

隐马尔可夫模型成为主流统计方法，结合高斯混合模型建模声学特征，开启长达30年的HMM时代。

2009 DNN 革命

Hinton等人提出用深度神经网络替代GMM，DNN-HMM大幅提升识别准确率。

2014-2016 端到端时代

Graves的CTC、Bahdanau的注意力机制、Chan的LAS模型相继提出，打破传统流水线解耦。

2020-2022 Transformer与大模型

Conformer结合卷积与Transformer优势，OpenAI Whisper展示大规模弱监督预训练的威力，通用ASR时代到来。

🔊 语音信号的本质

理解ASR的第一步是理解语音信号本身。语音本质上是空气振动产生的声波，通过麦克风转换成数字信号后被计算机处理。

语音产生机制

  • 声源：肺部气流冲击声带产生振动（浊音），或气流通过狭窄通道产生湍流（清音）
  • 声道：咽腔、口腔、鼻腔构成谐振腔，相当于一个时变滤波器
  • 共振峰：声道谐振频率，决定元音的音色差异（F1, F2, F3）
  • 基频F0：声带振动频率，决定音高（男性80-180Hz，女性160-320Hz）

数字信号采样

  • 采样率：语音常用16kHz（电话8kHz，高保真48kHz）
  • 量化位深：通常16-bit，每个采样点取值范围[-32768, 32767]
  • 奈奎斯特定理：采样率需大于最高频率的2倍才能无失真重建
  • 帧长：语音分帧处理，通常25ms一帧，帧移10ms

⚙️ 预处理四步曲

原始语音波形不能直接送入模型，需要经过标准预处理流程，将一维时域信号转换为适合建模的特征表示。

语音波形 ↓ [1] 预加重 (Pre-emphasis) ↓ [2] 分帧 (Framing) ↓ [3] 加窗 (Windowing) ↓ [4] 短时傅里叶变换 (STFT) ↓ 功率谱 / 幅度谱 ↓ 梅尔滤波 → FBANK ↓ 离散余弦变换(DCT) → MFCC

1. 预加重

语音信号中高频能量通常较弱，预加重通过一个一阶高通滤波器提升高频分量，平衡频谱：

$$ y(t) = x(t) - \alpha \cdot x(t-1), \quad \alpha \approx 0.97 $$

2. 分帧

语音是短时平稳信号（约10-30ms内统计特性近似不变），将信号切成25ms的帧，帧移10ms（相邻帧重叠15ms），保证帧间平滑。

⚠️ 为什么是25ms？

如果帧太短，频率分辨率不足；如果帧太长，信号已不再平稳，无法假设其频谱稳定。20-30ms是经过大量实验验证的经验最优值。

3. 加窗

直接对帧截断会导致频谱泄漏（吉布斯现象），需要乘以窗函数使帧两端平滑过渡到0。最常用汉明窗(Hamming)：

$$ w(n) = 0.54 - 0.46 \cos\left(\frac{2\pi n}{N-1}\right), \quad 0 \le n \le N-1 $$

4. STFT 短时傅里叶变换

对每一帧加窗后做N点FFT（通常N=512），得到短时频谱，每一帧对应一个频谱向量，最终形成(T, F)的时频谱图。

📐 傅里叶变换：信号的"透视镜"

傅里叶变换是语音信号处理最核心的数学工具。它告诉我们：任何复杂信号都可以分解为不同频率正弦波的叠加。

$$ X(\omega) = \int_{-\infty}^{\infty} x(t) e^{-j\omega t} dt $$

连续傅里叶变换：将时域信号x(t)分解为各频率分量的幅度和相位

🎵 音乐类比

想象你在听交响乐，傅里叶变换就像能"听出"每种乐器正在演奏什么音——它把复杂的合声音响分解成各个频率（音高）的组成成分。对语音来说，它告诉我们每一时刻哪些频率（对应声道形状、共振峰）在振动。

🎛️ 特征提取：从波形到特征向量

原始波形维度高、冗余大，直接送模型效果差。特征提取就是从波形中提取与语音内容相关、压缩掉无关信息（如音高、音量）的紧凑表示。

MFCC 梅尔频率倒谱系数

MFCC是GMM-HMM时代最主流的特征，模拟人耳听觉感知特性。它的提取过程共有7步：

  1. 预加重 → 分帧 → 加窗 → STFT：得到幅度谱（前面已讲）
  2. 计算功率谱：幅度谱取平方，|X(ω)|²
  3. 梅尔滤波器组：用一组三角带通滤波器（在梅尔刻度上等距分布）滤波，将线性频率映射到梅尔频率，模拟人耳对低频更敏感
  4. 取对数：对每个滤波器输出取对数，模拟人耳响度感知（分贝尺度）
  5. 离散余弦变换(DCT)：对滤波器组输出做DCT，去相关得到倒谱系数
  6. 保留前13维：通常取前12-13维DCT系数（高阶系数变化快，主要是激励细节）
  7. 加动态特征：一阶差分(Δ) + 二阶差分(ΔΔ)，共39维特征
📐 梅尔频率刻度
$$ f_{mel} = 2595 \cdot \log_{10}\left(1 + \frac{f}{700}\right) $$

1kHz以下近似线性，1kHz以上近似对数，完美匹配人耳听觉

FBANK (Filter Bank) 特征

FBANK是MFCC的前半部分——做完梅尔滤波、取对数后，不做DCT直接使用的特征。

  • 通常取40维或80维滤波器组输出
  • 保留了滤波器组输出之间的相关性，DNN可以自动学习去相关
  • 深度学习时代ASR普遍使用FBANK替代MFCC，因为DCT是线性变换，DNN完全可以学到
  • 端到端模型中几乎全部使用80维log-mel滤波器组特征
💡 经验之谈

在现代端到端ASR中，直接使用80维FBANK特征是标准配置；MFCC因为DCT做了去相关，更适合GMM这种假设特征独立的模型。

🏗️ 传统ASR完整流水线

在深度学习到来之前，ASR是一个高度解耦的模块化系统，由四个核心组件构成：

┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐ │ 特征提取 │ → │ 声学模型 │ → │ 解码 │ → │ 输出文本 │ │ (MFCC等) │ │ (GMM/DNN) │ │ (WFST) │ │ │ └──────────┘ └────┬─────┘ └────▲─────┘ └──────────┘ │ │ P(帧|音素) ┌──────┴──────┐ │ 发音词典 │ │ (Lexicon) │ └──────▲──────┘ │ ┌──────┴──────┐ │ 语言模型 │ │ (N-gram) │ │ P(词序列) │ └─────────────┘

声学模型 AM

建模 P(声学特征 | 音素状态)，给定发音单元，计算观测到该帧语音特征的概率。从GMM发展到DNN/CNN/RNN。

发音词典 Lexicon

定义词到音素序列的映射，例如"你好"→"n i3 h au3"。连接声学模型（音素级）和语言模型（词级）的桥梁。

语言模型 LM

建模 P(词序列)，衡量词序列出现的先验概率。帮助区分发音相同的词（如"戴"vs"带"），提供语义约束。

解码器 Decoder

结合声学得分和语言模型得分，在巨大的搜索空间中寻找最可能的词序列。使用WFST（加权有限状态转换器）HCLG图高效搜索。

🎯 贝叶斯决策公式
$$ \hat{W} = \arg\max_W P(W|O) = \arg\max_W \underbrace{P(O|W)}_{声学模型} \cdot \underbrace{P(W)}_{语言模型} $$

ASR的核心就是在给定观测语音O时，找到后验概率最大的词序列W。贝叶斯公式将其分解为声学似然×语言模型先验。

🔮 GMM-HMM：统治三十年的经典框架

隐马尔可夫模型（HMM）是传统ASR的基石。它非常巧妙地解决了语音时序对齐的核心问题。

HMM的基本假设

  • 马尔可夫性：当前状态只依赖于前一个状态（一阶马尔可夫）
  • 观测独立：当前帧观测只依赖于当前状态
  • 每个音素对应一个3状态HMM（开始/中间/结束），状态间转移建模时序

HMM三要素

要素符号含义在ASR中
初始概率π开始时在各状态的概率通常从句子开头状态开始
转移概率A从状态i转移到状态j的概率控制时序推进，只能自环或向右
观测概率B在状态j下观测到o_t的概率由GMM建模（GMM-HMM）或DNN计算（DNN-HMM）
🧩 为什么用HMM？

因为同样一句话说出来时长每次都不一样，我们不知道每个音素对应到哪几帧。HMM通过隐含状态序列和Viterbi算法自动找到最优对齐路径，这就是"隐"的含义——状态序列是隐藏的，我们只能观测到声学特征。

🔍 Viterbi解码与WFST

解码就是在给定观测特征序列时，搜索概率最大的词序列。Viterbi算法是HMM上的动态规划解码算法。

# Viterbi 算法核心思想 (伪代码) for t = 1 to T: for each state j: v[t][j] = max_i (v[t-1][i] * a[i][j]) * b[j][o_t] backpointer[t][j] = argmax_i (...) # 回溯最优路径 best_path[T] = argmax_j v[T][j] for t = T-1 down to 1: best_path[t] = backpointer[t+1][best_path[t+1]]

现代ASR系统将H(HMM)、C(上下文相关)、L(发音词典)、G(语言模型)四个WFST组合成统一的HCLG解码图，实现非常高效的静态搜索。

🚀 端到端ASR革命

传统ASR系统组件繁多、训练复杂、需要专家知识调优。端到端ASR的核心思想是：用一个神经网络直接输入语音特征、输出文本，不需要显式的发音词典、HMM、分段式训练。

传统ASR: 特征 → AM → HMM → 词典 → LM → 解码 → 文本 (多模块独立训练，需要发音词典和对齐) 端到端ASR: 特征 → Encoder → Decoder → CTC/Attention → 文本 (一个神经网络，端到端联合优化)

目前端到端ASR三大主流范式：CTC、Attention (Seq2Seq)、RNN-Transducer。

🔗 CTC：连接时序分类

CTC (Connectionist Temporal Classification) 是Alex Graves在2006年提出的方法，核心是解决输入输出长度不一致、无需逐帧标注对齐的问题。

核心思想：引入blank符号

在输出标签集中增加一个特殊的blank符号"∅"，允许模型在某些帧输出blank，并定义一个多对一的映射B：

  • 先合并连续重复字符
  • 再去掉所有blank符号
  • 例如：aa∅b∅∅cc → a b c
📐 CTC损失函数
$$ P(y|x) = \sum_{\pi \in \mathcal{B}^{-1}(y)} \prod_{t=1}^{T} P(\pi_t | x_t) $$

所有经过B映射后能得到标签序列y的路径π的概率之和，用动态规划（前向-后向算法）高效计算

🎮 通俗理解

想象你在抄写黑板上逐帧闪过的字。有的帧你看不清（输出blank），有的帧同一个字连续出现了好多次。最后你把重复的字合并、跳过看不清的，就得到了正确的句子。CTC让神经网络可以自己"决定"什么时候输出什么字、什么时候不输出，不需要人工标注每帧对应哪个字。

📝 小测验：在CTC中，路径"∅ hh ∅ ee ∅ l l ∅ oo ∅"经过B映射后得到什么？
A. ∅h∅e∅ll∅o∅
B. helo
C. hello
D. h e l o

🎯 Attention 序列到序列模型

基于注意力机制的Seq2Seq模型（如Listen-Attend-Spell）借鉴机器翻译，用编码器将语音编码为高级表示，解码器自回归生成字符，注意力模块动态对齐。

  • Encoder (Listener)：多层RNN/Transformer，将长度T的语音序列下采样到长度T/4的高级表示
  • Attention：解码每一步时，动态计算当前需要关注编码器哪些时间步的信息（软对齐）
  • Decoder (Speller)：类似语言模型，自回归逐字符生成输出，每一步依赖之前生成的字
$$ \text{Attention}(Q,K,V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) V $$

缩放点积注意力（Transformer中使用的形式）

纯Attention模型无需条件独立假设，对齐更灵活，但训练和推理速度慢，且存在输出重复/遗漏问题（对语音来说长度偏差明显），因此实际中经常和CTC联合训练（多任务学习）。

🔄 RNN-Transducer

RNN-T是Google提出的流式端到端模型，专为语音这种序列转换设计（输入输出长度不同且单调）。它在CTC基础上增加了预测网络（语言模型组件），支持逐帧流式输出，适合实时语音识别。

  • 包含Encoder(声学) + Predict网络(文本上下文) + Joint网络(融合二者)
  • 除blank外，每次输出非blank标签时预测网络前进一步
  • 严格单调对齐，天然适合流式识别
  • 是Google、百度等商业ASR系统的核心模型

🎭 Conformer：CNN与Transformer的完美结合

Conformer (Convolution-augmented Transformer) 是Google在2020年提出的编码器架构，现已成为端到端ASR的事实标准主干。

💡 核心洞察

Transformer的自注意力擅长全局长距离依赖，CNN擅长局部特征提取。语音信号同时需要两者：局部需要提取发音细节，全局需要捕获上下文语义。Conformer将二者结合，每个模块依次是：FFN → Multi-Head Self-Attention → Convolution → FFN，用Macaron结构替换原始Transformer。

📦 经典模型解析：DeepSpeech

2014 DeepSpeech (Baidu/Mozilla)
RNN + CTC

Mozilla DeepSpeech是开源端到端ASR的经典之作，架构简单但非常有效：

  • 输入层：26维MFCC特征（或FBANK）
  • 5层：1层全连接 + 3层双向LSTM + 1层全连接
  • 输出层：字符数+1个单元（含blank），CTC损失训练
  • 使用N-gram语言模型在解码时做shallow fusion
  • 证明了端到端ASR可以匹敌甚至超过传统GMM-HMM系统

📦 经典模型解析：Listen-Attend-Spell

2015 LAS (Listen, Attend and Spell)
Attention Seq2Seq

William Chan等人提出，是第一个将机器翻译Seq2Seq框架完全应用到语音识别的代表作：

  • Listener：金字塔BiLSTM，逐层下采样（时间分辨率逐层减半）
  • Attend：加性注意力机制，动态计算对编码器隐状态的关注权重
  • Speller：2层LSTM解码器，自回归逐字符生成
  • 缺点：非单调，需要整句话后才能处理，无法流式识别

🤖 经典模型解析：OpenAI Whisper

2022 Whisper (OpenAI)
大规模弱监督预训练

Whisper是ASR领域最重要的近期工作之一，它证明了用海量弱标注互联网数据预训练，可以得到鲁棒的多语言通用ASR模型。

核心特点

  • 数据规模：68万小时音频-文本对，其中11.7万小时多语言，12.5万小时翻译数据
  • 架构：标准Transformer Encoder-Decoder，没有特殊创新
  • 多任务：同时预测语言、是否有语音、时间戳、转录文本、翻译文本
  • 训练：简单的下一个token预测目标，用特殊token区分任务类型
  • 模型尺寸：tiny(39M)→base(74M)→small(244M)→medium(769M)→large(1550M)
🌟 Whisper的真正贡献

不是架构创新，而是数据规模和多样性带来的超强泛化能力。它在口音、噪声、专业术语、多语言混读场景下的鲁棒性远超之前所有开源模型，彻底改变了ASR落地门槛。

import whisper # 加载模型 (首次会自动下载) # 可选: tiny, base, small, medium, large model = whisper.load_model("base") # 识别音频 (支持wav/mp3/flac/m4a等多种格式) result = model.transcribe("audio.wav", language="zh") # 输出完整文本 print(result["text"]) # 输出带时间戳的片段 for seg in result["segments"]: print(f"[{seg['start']:.1f}s - {seg['end']:.1f}s] {seg['text']}")

命令行使用

# 基本用法 whisper audio.mp3 --model small --language zh # 输出多种格式 (txt/vtt/srt/tsv/json) whisper interview.wav --model medium --output_format srt
