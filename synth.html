🧪 参数化共振峰合成探索器

拖动滑块调节 F0（基频）、F1/F2/F3（共振峰）、带宽、声门脉冲、噪声比例，
实时听合成出来的元音——原来 [i] 就是 F1 低 + F2 高 + F3 低！比看公式直观100倍。

预设元音： 未启动

🎚️ 合成参数控制面板

F0 基频160 Hz
F1 第一共振峰700 Hz
F2 第二共振峰1200 Hz
F3 第三共振峰2600 Hz
BW1 F1带宽80 Hz
BW2 F2带宽100 Hz
BW3 F3带宽150 Hz
OQ 声门开闭比0.55
Aspiration 气声噪声0.02
Vibrato 颤音深度0 Hz
音量0.3
频谱 F1/F2/F3 共振峰 右下角：当前元音在 IPA 元音图位置 ●

🔬 原理：源-滤波器理论（Source-Filter Theory）

数据流向：声门振动产生脉冲 → 声道像管子一样共振（选频放大）→ 嘴唇向外辐射 → 听到元音

📐 源-滤波器理论（Gunnar Fant, 1960）：

Speech(t) = Source(t) * VocalTract(t) 　（* 表示卷积，不是乘法）

声源（声带振动产生的周期性脉冲）与声道（共振峰滤波响应）在频域相乘、时域卷积，最终输出语音信号。

🐍 手搓元音合成（极简 NumPy 版，15行核心代码）

import numpy as np
from scipy.signal import lfilter

fs = 16000; dur = 1.0; f0 = 160          # 采样率16k，时长1s，基频160Hz
t = np.arange(fs*dur)/fs
# 1) 声源：三角波脉冲串（模拟声门振动）
phase = (t*f0) % 1.0
source = np.where(phase<0.5, 2*phase, 2*(1-phase)) * 2 - 1   # 三角波 [-1,1]

# 2) 声道：3个并联/串联二阶IIR谐振滤波器（共振峰）
def resonator(f, bw, fs):              # 二阶谐振器系数
    r = np.exp(-np.pi*bw/fs); c = -r*r
    b = [1-r, 0, r-c-1]                # 简化系数，真实Klatt合成器更复杂
    a = [1, -2*r*np.cos(2*np.pi*f/fs), r*r]
    return b, a

# 目标元音 [ɑ]：F1=730 F2=1090 F3=2600 (Hz)
x = source
for F,BW in [(730,80),(1090,100),(2600,150)]:
    b,a = resonator(F, BW, fs)
    x = lfilter(b, a, x)

# 3) 嘴唇辐射：一阶差分（高通 +6dB/oct）
speech = np.diff(x, prepend=0) * 0.1
# speech 就是合成的元音 "啊" 🎉 ——把共振峰值换成 (270,2290,3000) 就是 "衣"！
💡 核心洞察： 决定你听到"啊/衣/乌"的不是 F0（那是音调高低），而是 F1、F2、F3 三个共振峰的位置—— 它们就是声道这根"管子"在不同形状下的固有频率。本页面就是用 WebAudio 的 BiquadFilter 实时把这三步做了一遍， 你拖滑块就是在"捏管子"。
