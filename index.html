语音技术全景演进

从统计建模到深度学习，语音技术经历了数次范式变革，每一次突破都推动着人机交互的边界

📊

传统统计时代

GMM-HMM框架主导数十年，ASR依赖手工设计特征(MFCC)和声学/语言模型解耦；TTS以单元拼接和参数合成为主，自然度有限。

1980s - 2010
🧠

深度学习革命

DNN替代GMM，端到端框架(CTC/Attention/RNN-T)打破HMM束缚；Tacotron+WaveNet让TTS自然度首次接近真人。

2012 - 2020
🚀

大模型时代

Whisper展示大规模预训练的威力，ASR走向通用多语言；VALL-E实现3秒零样本克隆，VITS一统端到端TTS，语音大模型正在涌现。

2020 - 至今

📚 循序渐进学习路径

从零基础到掌握前沿，推荐按以下四个阶段系统学习

阶段 1

数学与信号基础

打好基础是理解语音技术的前提，这一阶段重点掌握必要的数学和信号处理知识。

  • • 微积分、线性代数、概率统计（贝叶斯、隐马尔可夫模型）
  • • 傅里叶变换、短时傅里叶变换(STFT)、数字信号处理基础
  • • 语音学基础：发音机制、音素、共振峰、基频F0
  • • Python基础 + NumPy + PyTorch/TensorFlow 深度学习框架
阶段 2

ASR 基础：从特征到HMM

理解传统语音识别的完整流水线，为理解端到端方法建立对比基准。

  • • 预处理：预加重、分帧、加窗、快速傅里叶变换
  • • 特征提取：梅尔滤波器组、FBANK、MFCC 原理与实现
  • • GMM-HMM框架：声学模型、发音词典、语言模型、Viterbi解码
  • • Kaldi工具入门：跑通第一个识别脚本，理解HCLG解码图
阶段 3

TTS 基础：前端与传统合成

掌握语音合成的前端处理流程和传统合成方法的核心思想。

  • • 文本前端：文本归一化、分词、G2P、韵律边界预测
  • • 源-滤波器模型：声门源、声道滤波、线性预测LPC
  • • 单元拼接合成与统计参数合成(HTS)的原理与局限
  • • STRAIGHT、WORLD等经典声码器原理
阶段 4

深度学习前沿：端到端语音技术

深入学习基于深度学习的端到端方法，掌握当前主流模型架构。

ASR 方向
  • • CTC损失函数与RNN-T序列转换
  • • Attention序列到序列模型(LAS)
  • • Transformer/Conformer 主干网络
  • • OpenAI Whisper 大规模预训练模型
  • • WeNet / ESPnet / FunASR 实战
TTS 方向
  • • Seq2Seq自回归：Tacotron2 / DeepVoice

  • • 零样本克隆：VALL-E / Voicebox
  • • 对话TTS：ChatTTS / Bark / SpeechT5

🧮 核心数学基础

短时傅里叶变换 (STFT)

语音是时变信号，需要通过短时傅里叶变换获取时频表示，这是所有语音特征提取的基础。

$$ X(t, \omega) = \int_{-\infty}^{\infty} x(\tau) w(\tau - t) e^{-j\omega\tau} d\tau $$

其中 w(·) 是窗函数（常用汉明窗），t 是帧位置，ω 是角频率

梅尔频率倒谱系数 (MFCC)

模拟人耳听觉特性的特征表示，曾是GMM-HMM时代ASR的标准特征。

$$ f_{mel} = 2595 \cdot \log_{10}\left(1 + \frac{f}{700}\right) $$

将线性频率映射到梅尔刻度，模拟人耳对低频更敏感的特性

CTC 目标函数

引入空白符(blank)解决输入输出长度不一致问题，无需逐帧对齐标注。

$$ P(y|x) = \sum_{\pi \in \mathcal{B}^{-1}(y)} \prod_{t=1}^{T} P(\pi_t | x_t) $$

B是去重去blank映射，将所有可能对齐路径求和

神经声码器 (HiFi-GAN)

使用生成对抗网络从梅尔谱图重建高保真语音波形。

$$ \min_G \max_D \mathcal{L}_{adv}(G,D) + \lambda_{fm}\mathcal{L}_{fm} + \lambda_{mel}\mathcal{L}_{mel} $$

多周期判别器+多尺度判别器，结合对抗损失、特征匹配损失和梅尔谱损失

⚡ 5分钟快速上手

使用 OpenAI Whisper 进行语音识别，只需3行代码：

# 安装依赖
pip install openai-whisper ffmpeg-python

# Python 代码
import whisper
model = whisper.load_model("base")
result = model.transcribe("audio.wav")
print(result["text"])

使用 Coqui TTS 进行语音合成，快速生成自然语音：

# 安装依赖
pip install TTS

# Python 代码
from TTS.api import TTS
tts = TTS(model_name="tts_models/en/ljspeech/tacotron2-DDC", progress_bar=False)
tts.tts_to_file(text="Hello, welcome to Agent Speech world!", file_path="output.wav")
